# Модуль `models`

## Описание

Модуль `models` содержит типы данных и интерфейсы, используемые для представления структур данных в проекте. Он предоставляет базовые сущности для работы с изменениями, кодом, версиями и конфликтами в системе управления версиями.

## Файлы

| Файл | Описание |
|------|----------|
| `change-intent.ts` | Определяет интерфейс для описания намерения изменения, включая тип изменения и связанные с ним данные |
| `code-unit.ts` | Определяет структуру кодовой единицы, используемую для представления частей исходного кода |
| `index.ts` | Экспортирует все модели из модуля, обеспечивая централизованный доступ к типам данных |
| `merge-result.ts` | Описывает результат слияния изменений, включая успешные и неуспешные операции |
| `semantic-conflict.ts` | Определяет типы для представления семантических конфликтов при слиянии кода |
| `versioned-index.ts` | Предоставляет структуру индекса с версионированием для отслеживания изменений в коде |

## Экспорты

Внутренний модуль без публичных экспортов.

## Использование

Для использования моделей в проекте импортируйте нужные типы из модуля:

```typescript
import type { ChangeIntent, CodeUnit } from './models';
```
