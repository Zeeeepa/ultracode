# Модуль models

## Описание

Модуль `models` содержит типы данных и интерфейсы, используемые для представления структурных элементов проекта, таких как изменения, кодовые единицы, версии и результаты слияния. Этот модуль служит основой для работы с семантическими конфликтами и управлением версиями в системе.

## Файлы

| Файл | Описание |
|------|----------|
| `change-intent.ts` | Определяет интерфейс для описания намерения изменения, включая тип изменения и связанные с ним данные |
| `code-unit.ts` | Определяет структуру кодовой единицы, используемую для представления отдельных частей исходного кода |
| `index.ts` | Экспортирует все модели из модуля, обеспечивая удобный доступ к типам данных |
| `merge-result.ts` | Описывает результаты слияния изменений, включая успешные и неудачные операции |
| `semantic-conflict.ts` | Определяет типы для представления семантических конфликтов между различными версиями кода |
| `versioned-index.ts` | Предоставляет структуру для хранения и управления версиями индексов кода |

## Экспорты

Внутренний модуль без публичных экспортов. Все типы и интерфейсы предназначены для использования внутри модуля.

## Использование

```typescript
import { ChangeIntent, CodeUnit, MergeResult } from './models';

// Использование типов для работы с данными
const change: ChangeIntent = {
  type: 'add',
  unit: new CodeUnit('function test() {}'),
  result: new MergeResult(true)
};
```
