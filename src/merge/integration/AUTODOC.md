# Модуль интеграции (integration)

## Описание

Модуль интеграции предоставляет функциональность для работы с внешними системами и сервисами через Git. Содержит реализации для взаимодействия с репозиториями и управления интеграциями.

## Файлы

| Файл              | Описание                                                                 |
|-------------------|--------------------------------------------------------------------------|
| `git-integration.ts` | Реализация интеграции с Git репозиториями, включая операции клонирования, получения статуса и работы с ветками. |
| `index.ts`         | Точка входа модуля, экспортирует внутренние компоненты для использования в других частях приложения. |

## Экспорты

> В данном модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования.

## Использование

Данный модуль используется внутри приложения для автоматизации процессов работы с Git репозиториями. Пример использования:

```typescript
import { GitIntegration } from './integration/git-integration';

const git = new GitIntegration();
await git.cloneRepository('https://github.com/example/repo.git');
```

> Обратите внимание, что модуль предназначен для внутреннего использования и не предполагает прямого импорта извне.
