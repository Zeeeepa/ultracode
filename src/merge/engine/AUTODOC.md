# Engine Module

## Title and Overview

Модуль `engine` предоставляет инструменты для разрешения конфликтов версий и слияния данных в многоверсионных системах. Включает реализации конфликтного разрешения с использованием ИИ и традиционных алгоритмов, а также инструменты для трехстороннего слияния данных. Модуль предназначен для работы с версионированными данными и обеспечивает надежное разрешение конфликтов при совместной работе.

## Files

| File | Description |
|------|-------------|
| `ai-conflict-resolver.ts` | Реализация разрешения конфликтов с использованием искусственного интеллекта для принятия решений о разрешении конфликтов данных. |
| `conflict-resolver.ts` | Базовая реализация алгоритмов разрешения конфликтов для многоверсионных данных. |
| `index.ts` | Точка входа модуля, экспортирующая основные классы и функции для работы с движком. |
| `three-way-merger.ts` | Инструмент для выполнения трехстороннего слияния данных из трех различных источников или версий. |

## Exports

### `MultiVersionIndexer`
Класс для индексации и управления многоверсионными данными, обеспечивает быстрый доступ к различным версиям данных по ключу.

### `AIConflictResolver`
Реализация разрешения конфликтов с использованием ИИ, которая анализирует конфликты и предлагает оптимальные решения для их разрешения.

### `ConflictResolver`
Базовый класс для разрешения конфликтов версий данных, содержит общие методы и интерфейсы для работы с конфликтами.

### `ThreeWayMerger`
Инструмент для выполнения трехстороннего слияния данных, используемый при объединении изменений из трех различных источников.

## Usage

```typescript
import { ThreeWayMerger, AIConflictResolver } from './engine';

const merger = new ThreeWayMerger();
const resolver = new AIConflictResolver();

// Пример использования
const result = merger.merge(base, ours, theirs);
const resolved = resolver.resolve(conflict);
```
