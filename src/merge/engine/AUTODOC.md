# Engine Module Documentation

## Title and Overview

Модуль `engine` предоставляет инструменты для разрешения конфликтов версий данных и слияния изменений в распределённых системах. Он включает реализации конфликтного разрешения с использованием ИИ и традиционных алгоритмов, а также механизм трёхстороннего слияния для эффективной работы с версиями.

## Files

| File | Description |
|------|-------------|
| `ai-conflict-resolver.ts` | Реализация разрешения конфликтов с использованием искусственного интеллекта для принятия решений при конфликтах данных |
| `conflict-resolver.ts` | Традиционная реализация разрешения конфликтов версий данных с поддержкой различных стратегий разрешения |
| `index.ts` | Точка входа модуля, экспортирующая основные классы и интерфейсы для работы с движком |
| `three-way-merger.ts` | Механизм трёхстороннего слияния данных, используемый для объединения изменений из трёх различных источников |

## Exports

- **`MultiVersionIndexer`** — класс для индексации и управления множественными версиями данных
- **`AIConflictResolver`** — реализация разрешения конфликтов с использованием ИИ
- **`ConflictResolver`** — основной класс для разрешения конфликтов версий данных
- **`ThreeWayMerger`** — инструмент для трёхстороннего слияния изменений

## Usage

```typescript
import { ConflictResolver, ThreeWayMerger } from './engine';

const resolver = new ConflictResolver();
const merger = new ThreeWayMerger();

// Использование для разрешения конфликтов
const result = resolver.resolve(conflictData);

// Использование для слияния изменений
const merged = merger.merge(base, ours, theirs);
```
