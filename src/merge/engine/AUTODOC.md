# Engine Module Documentation

## Title and Overview

Модуль `engine` предоставляет инструменты для разрешения конфликтов версий и слияния данных в распределенных системах. Он включает реализации конфликтного разрешения с использованием ИИ и традиционных алгоритмов, а также механизм трехстороннего слияния для управления версиями. Модуль предназначен для работы с системами контроля версий и синхронизации данных.

## Files

| File | Description |
|------|-------------|
| `ai-conflict-resolver.ts` | Реализация разрешения конфликтов с использованием искусственного интеллекта для принятия решений о разрешении конфликтов данных. |
| `conflict-resolver.ts` | Традиционная реализация разрешения конфликтов версий с поддержкой различных стратегий разрешения. |
| `index.ts` | Точка входа модуля, экспортирующая основные классы и функции для использования в других частях проекта. |
| `three-way-merger.ts` | Реализация трехстороннего слияния данных для объединения изменений из трех различных источников. |

## Exports

- **`MultiVersionIndexer`** — класс для индексирования и управления многоверсионными данными в системе.
- **`AIConflictResolver`** — реализация разрешения конфликтов с использованием ИИ для принятия оптимальных решений.
- **`ConflictResolver`** — базовая реализация разрешения конфликтов версий с поддержкой различных стратегий.
- **`ThreeWayMerger`** — инструмент для выполнения трехстороннего слияния данных из трех источников.

## Usage

```typescript
import { ThreeWayMerger, ConflictResolver } from './engine';

const merger = new ThreeWayMerger();
const resolver = new ConflictResolver();
```

Используйте `ThreeWayMerger` для слияния изменений из трех источников, а `ConflictResolver` для разрешения конфликтов версий. Для ИИ-основанного разрешения конфликтов используйте `AIConflictResolver`.
