# Модуль индексирования

## Описание

Модуль индексирования отвечает за подготовку и управление структурой данных перед индексацией в системе поиска. Включает в себя нормализацию контента, генерацию сигнатур, кэширование векторных представлений и управление версиями индексов.

## Файлы

| Файл | Описание |
|------|----------|
| `content-normalizer.ts` | Нормализует текстовый контент для последующей индексации, удаляет лишние пробелы и приводит текст к единому формату |
| `index.ts` | Основной модуль индексирования, содержит логику сборки и управления индексами |
| `lazy-embedding-cache.ts` | Реализует ленивое кэширование векторных представлений (embedding) для ускорения индексации |
| `multi-version-indexer.ts` | Поддерживает работу с несколькими версиями индекса, обеспечивает совместимость при обновлениях |
| `signature-generator.ts` | Генерирует уникальные сигнатуры для документов, используемые для идентификации и сравнения |
| `structural-normalizer.ts` | Нормализует структуру данных, приводит разные форматы к единому представлению перед индексацией |

## Экспорты

Данный модуль не имеет публичных экспортов и предназначен исключительно для внутреннего использования.

## Использование

Модуль используется внутренне системой индексирования и не требует прямого вызова извне. Пример использования:

```typescript
// Внутреннее использование
import { MultiVersionIndexer } from './multi-version-indexer';
import { ContentNormalizer } from './content-normalizer';
```
