# Модуль индексирования

## Описание модуля

Модуль индексирования отвечает за подготовку и управление индексами контента, включая нормализацию данных, генерацию сигнатур, кэширование векторных представлений и управление версиями индексов. Используется для создания оптимизированных индексов с поддержкой различных форматов и версий данных.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `content-normalizer.ts` | Нормализует содержимое для индексации, приводя его к стандартному виду и удаляя избыточные данные |
| `index.ts` | Основной файл модуля, содержит логику инициализации и взаимодействия компонентов индексирования |
| `lazy-embedding-cache.ts` | Реализует ленивое кэширование векторных представлений (embedding) для ускорения индексации |
| `multi-version-indexer.ts` | Поддерживает работу с несколькими версиями индексов, позволяя управлять обновлениями и обратной совместимостью |
| `signature-generator.ts` | Генерирует уникальные сигнатуры для контента, используемые для идентификации и сравнения документов |
| `structural-normalizer.ts` | Нормализует структурные элементы контента, приводя их к единообразному формату для индексации |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

Модуль используется внутри системы индексирования для подготовки и управления контентом перед созданием индексов. Пример использования:

```typescript
import { MultiVersionIndexer } from './indexing/multi-version-indexer';
import { ContentNormalizer } from './indexing/content-normalizer';

const indexer = new MultiVersionIndexer();
const normalizer = new ContentNormalizer();
```
