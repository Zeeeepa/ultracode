# Модуль индексирования

## Описание модуля

Модуль индексирования отвечает за подготовку и управление данными для поиска и индексации. Включает в себя нормализацию контента, генерацию сигнатур, кэширование векторных представлений и управление версиями индексов. Предназначен для внутреннего использования в системе поиска и индексации данных.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `content-normalizer.ts` | Нормализует текстовый контент для последующей индексации, удаляет лишние символы и приводит текст к единому формату |
| `index.ts` | Основной файл модуля, содержит логику инициализации и связывания компонентов индексирования |
| `lazy-embedding-cache.ts` | Реализует ленивое кэширование векторных представлений (embedding) для ускорения поиска и индексации |
| `multi-version-indexer.ts` | Управляет созданием и обслуживанием нескольких версий индекса для обеспечения совместимости и обновления данных |
| `signature-generator.ts` | Генерирует уникальные сигнатуры для документов, используемые для определения их идентичности и дедупликации |
| `structural-normalizer.ts` | Нормализует структурированные данные (JSON, XML и т.п.) для корректного индексирования и поиска |

## Экспорты

В модуле отсутствуют публичные экспорты. Все компоненты предназначены для внутреннего использования.

## Использование

Модуль используется внутренне системой индексирования и не требует прямого вызова извне. Пример использования:

```typescript
// Внутреннее использование
import { MultiVersionIndexer } from './multi-version-indexer';
import { ContentNormalizer } from './content-normalizer';
// и т.д.
```
