# Модуль merge

## Описание

Модуль `merge` предназначен для объединения данных из различных источников в единый объект. Используется для слияния конфигураций, параметров и других структур данных с сохранением иерархии и приоритетов. Внутренний модуль, не экспортирует публичные функции.

## Файлы

| Файл           | Описание                                       |
|----------------|------------------------------------------------|
| `index.ts`     | Основная реализация функции слияния данных       |

## Экспорты

Модуль не имеет публичных экспортов. Является внутренним модулем и используется только внутри проекта.

## Использование

```typescript
// Внутреннее использование внутри проекта
import { merge } from './merge';

const result = merge({ a: 1 }, { b: 2 }, { c: 3 });
// Результат: { a: 1, b: 2, c: 3 }
```
