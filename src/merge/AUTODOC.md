# Модуль merge

## Описание

Модуль `merge` предоставляет функционал для объединения (слияния) двух или более объектов в один. Используется для создания новых объектов с объединёнными свойствами, при этом сохраняя оригинальные объекты неизменными. Поддерживает глубокое слияние вложенных объектов и массивов.

## Файлы

| Файл         | Описание                                               |
|--------------|--------------------------------------------------------|
| `index.ts`   | Основная реализация функции слияния объектов            |

## Экспорты

Модуль не предоставляет публичных экспортов. Является внутренним модулем, используемым для выполнения операций слияния объектов в рамках проекта.

## Использование

```typescript
import { merge } from './merge';

const obj1 = { a: 1, b: { c: 2 } };
const obj2 = { b: { d: 3 }, e: 4 };

const merged = merge(obj1, obj2);
// Результат: { a: 1, b: { c: 2, d: 3 }, e: 4 }
```
