# CLI Модуль

## Описание

CLI модуль отвечает за настройку и управление командной строкой приложения. Содержит логику для инициализации команд и обработки пользовательского ввода.

## Файлы

| Файл                 | Описание                                       |
|----------------------|------------------------------------------------|
| `setup-command.ts`   | Реализует команду настройки приложения и инициализацию конфигурации |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Модуль предназначен для внутреннего использования и не предоставляет публичных интерфейсов.

## Использование

Модуль используется внутренне приложением для обработки команды `setup` в командной строке:

```bash
npm run setup
```
