# Модуль GPU

## Описание

Модуль **gpu** отвечает за управление графическими процессорами и выбор backend-ов для выполнения графических операций. Используется для оптимизации рендеринга и вычислений на GPU с автоматическим выбором наиболее подходящего драйвера в зависимости от доступных ресурсов системы.

## Файлы

| Файл                 | Описание                                                                 |
|----------------------|--------------------------------------------------------------------------|
| `backend-selector.ts` | Выполняет логику выбора подходящего GPU backend-а (WebGPU, WebGL и др.) |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Модуль предназначен для внутреннего использования и предоставляет функционал через импорты в других частях проекта.

## Использование

```typescript
import { selectBackend } from './gpu/backend-selector';

const backend = selectBackend();
// Используем backend для инициализации графических операций
```
