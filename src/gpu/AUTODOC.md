# Модуль GPU

## Описание

Модуль GPU отвечает за выбор и управление графическими процессорами (GPU) в приложении. Он обеспечивает автоматический подбор подходящего GPU-драйвера и предоставляет интерфейс для работы с графическими ресурсами. Модуль используется для оптимизации производительности приложений, работающих с графическими вычислениями и рендерингом.

## Файлы

| Файл | Описание |
|------|----------|
| `backend-selector.ts` | Выполняет логику выбора подходящего GPU-бэкенда на основе доступных ресурсов и конфигурации системы. Определяет, какой драйвер (DirectX, OpenGL, Vulkan и др.) будет использоваться для графических операций. |

## Экспорты

Модуль не имеет публичных экспортов. Является внутренним модулем и используется только внутри проекта для управления GPU-ресурсами.

## Использование

```typescript
// Использование модуля происходит автоматически при инициализации графической подсистемы
import { initializeGPU } from './gpu';

initializeGPU();
```

> Примечание: Модуль автоматически определяет доступные GPU-драйверы и настраивает их для работы с приложением. Пользователь не взаимодействует с ним напрямую.
