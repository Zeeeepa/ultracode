# Модуль обнаружения (detection)

## Описание модуля

Модуль `detection` предназначен для автоматического определения характеристик устройства пользователя, таких как доступность GPU и поддержка WebGL. Используется для оптимизации отображения контента в зависимости от возможностей устройства.

## Файлы модуля

| Файл             | Описание                                                                 |
|------------------|--------------------------------------------------------------------------|
| `gpu-detector.ts` | Обнаружение доступности и характеристик GPU устройства для оптимизации рендеринга |

## Экспорты

Модуль не имеет публичных экспортов. Является внутренним модулем и используется только внутри проекта.

## Использование

Модуль используется напрямую в компонентах рендеринга для выбора оптимальной стратегии отображения контента в зависимости от возможностей устройства. Пример использования:

```typescript
import { detectGPU } from './detection/gpu-detector';

const gpuInfo = detectGPU();
if (gpuInfo.supportsWebGL) {
  // Использовать WebGL рендеринг
} else {
  // Использовать альтернативный метод отображения
}
```
