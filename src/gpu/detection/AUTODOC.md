# Модуль обнаружения (detection)

## Описание модуля

Модуль обнаружения предназначен для определения характеристик устройства пользователя, таких как доступность GPU и возможности использования WebGL. Используется для адаптации интерфейса и выбора оптимальных настроек в зависимости от возможностей устройства.

## Файлы модуля

| Файл              | Описание                                                                 |
|-------------------|--------------------------------------------------------------------------|
| `gpu-detector.ts` | Обнаружение доступности и характеристик GPU устройства для WebGL и других графических функций |

## Экспорты

Модуль не имеет публичных экспортов. Является внутренним модулем, используемым для определения графических возможностей устройства.

## Использование

Модуль используется внутренне для определения возможностей устройства:

```typescript
import { detectGPU } from './detection/gpu-detector';

const gpuInfo = detectGPU();
if (gpuInfo.webGLSupported) {
  // Использовать WebGL
}
```
