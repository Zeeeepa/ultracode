# Модуль обнаружения (detection)

## Описание

Модуль обнаружения предназначен для определения характеристик устройства пользователя, таких как доступность GPU и поддержка WebGL. Используется для оптимизации отображения контента в зависимости от возможностей устройства.

## Файлы

| Файл              | Описание                                                                 |
|-------------------|--------------------------------------------------------------------------|
| `gpu-detector.ts` | Обнаружение доступности и характеристик GPU устройства для оптимизации рендеринга |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все функции предназначены для внутреннего использования.

## Использование

Модуль используется внутри приложения для автоматической настройки отображения графики в зависимости от возможностей устройства. Пример использования:

```typescript
import { detectGPU } from './detection/gpu-detector';

const gpuInfo = detectGPU();
if (gpuInfo.supportsWebGL) {
  // Включить WebGL-рендеринг
} else {
  // Использовать альтернативный рендеринг
}
```
