# Модуль backends

## Описание

Модуль `backends` предоставляет реализации различных вычислительных бэкендов для выполнения операций с данными. Он инкапсулирует логику работы с различными платформами и технологиями, такими как JavaScript, WebAssembly, CUDA и другие, позволяя выбирать оптимальный способ выполнения вычислений в зависимости от среды выполнения.

## Файлы

| Файл | Описание |
|------|----------|
| `base.ts` | Базовый класс для всех бэкендов, определяющий общий интерфейс и общую логику работы с вычислительными операциями |
| `cuda-backend.ts` | Реализация бэкенда для выполнения вычислений на GPU с использованием CUDA |
| `js-backend.ts` | Бэкенд для выполнения вычислений в JavaScript на CPU |
| `metal-backend.ts` | Реализация бэкенда для выполнения вычислений на GPU с использованием Metal API |
| `wasm-backend.ts` | Бэкенд для выполнения вычислений с использованием WebAssembly |
| `webgpu-backend.ts` | Реализация бэкенда для выполнения вычислений с использованием WebGPU |

## Экспорты

В модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

Модуль используется внутренне для выбора подходящего бэкенда в зависимости от доступных возможностей среды выполнения. Пример использования:

```typescript
import { getBackend } from './backends';

const backend = getBackend(); // автоматический выбор бэкенда
```

> Примечание: реализация `getBackend` и другие функции доступны только внутри модуля.
