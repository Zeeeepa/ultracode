# Автоматическая документация модуля "linters"

## Описание модуля

Модуль `linters` предоставляет инструменты для проверки кода на соответствие стандартам качества и стилю программирования. Он включает реализации линтеров для TypeScript и Python, которые могут использоваться в процессе разработки для автоматической проверки кода.

## Файлы модуля

| Файл                | Описание                                                                 |
|---------------------|--------------------------------------------------------------------------|
| `eslint-linter.ts`  | Реализация линтера для TypeScript с использованием ESLint для проверки кода. |
| `pylint-linter.ts`  | Реализация линтера для Python с использованием Pylint для проверки кода.     |

## Экспорты

В модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования.

## Использование

Данный модуль используется внутри других частей приложения для выполнения проверок кода. Пример использования:

```typescript
import { ESLintLinter } from './linters/eslint-linter';
import { PylintLinter } from './linters/pylint-linter';

const eslint = new ESLintLinter();
const pylint = new PylintLinter();

// Выполнение проверки кода
eslint.lint('src/**/*.ts');
pylint.lint('src/**/*.py');
```
