# Автоматическая документация модуля "linters"

## Описание модуля

Модуль `linters` предоставляет инструменты для проверки кода на соответствие стандартам и правилам качества. Он включает реализации линтеров для различных языков программирования, таких как TypeScript и Python. Данный модуль предназначен для интеграции в процессы непрерывной интеграции (CI) и автоматической проверки качества кода.

## Файлы модуля

| Файл               | Описание                                                   |
|--------------------|------------------------------------------------------------|
| `eslint-linter.ts` | Реализация линтера для TypeScript с использованием ESLint |
| `pylint-linter.ts` | Реализация линтера для Python с использованием Pylint    |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования и не предназначены для импорта из других модулей.

## Пример использования

Модуль используется внутри других частей системы для выполнения проверок кода. Пример использования:

```typescript
// Внутреннее использование в другом модуле
import { ESLintLinter } from './linters/eslint-linter';
import { PylintLinter } from './linters/pylint-linter';

const eslint = new ESLintLinter();
const pylint = new PylintLinter();

// Выполнение проверок
await eslint.lint('src/**/*.ts');
await pylint.lint('src/**/*.py');
```
