# Конфигурационный модуль

## Описание

Конфигурационный модуль отвечает за управление настройками приложения, включая константы, конфигурацию логирования и загрузку конфигураций из YAML-файлов. Предоставляет централизованный способ получения и управления конфигурационными данными проекта.

## Файлы

| Файл | Описание |
|------|----------|
| `constants.ts` | Определяет глобальные константы проекта, такие как порты, пути и другие фиксированные значения |
| `logging-config.ts` | Конфигурация системы логирования, включая уровни логирования и форматирование сообщений |
| `yaml-config.ts` | Логика загрузки и парсинга конфигурационных файлов в формате YAML |

## Экспорты

Внутренний модуль без публичных экспортов. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

```typescript
// Пример использования конфигурационного модуля
import { getConfig } from './config/yaml-config';

const config = getConfig();
console.log(config.database.url);
```

> Конфигурационные файлы должны находиться в директории `config/` и иметь расширение `.yaml` или `.yml`
