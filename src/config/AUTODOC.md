# Конфигурационный модуль

## Описание модуля

Конфигурационный модуль отвечает за управление настройками приложения, включая константы, конфигурацию логирования и загрузку конфигураций из YAML-файлов. Предоставляет централизованный способ работы с различными типами конфигураций внутри проекта.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `constants.ts` | Определяет глобальные константы проекта, используемые в различных частях приложения |
| `logging-config.ts` | Конфигурация системы логирования, включая уровни логирования и форматирование сообщений |
| `yaml-config.ts` | Логика загрузки и парсинга конфигурационных файлов в формате YAML |

## Экспорты

Внутренний модуль, не имеет публичных экспортов.

## Использование

Модуль используется напрямую в других частях приложения для получения конфигурационных значений:

```typescript
import { getConfig } from './config/yaml-config';

const config = getConfig();
```

> Примечание: Все файлы модуля импортируются и используются внутри проекта, без внешних публичных интерфейсов.
