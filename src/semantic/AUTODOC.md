# Модуль semantic

## Описание

Модуль `semantic` предоставляет набор инструментов для работы с семантическим анализом текста, включая генерацию векторных представлений, поиск по векторам, разбиение текста и кэширование результатов. Используется для реализации семантических функций в приложениях, таких как поиск по смыслу, анализ контента и интеллектуальная обработка текста.

## Файлы

| Файл                      | Описание                                                                 |
|---------------------------|--------------------------------------------------------------------------|
| `adaptive-vector-backend.ts` | Адаптивный бэкенд для работы с векторами, поддерживающий различные хранилища и стратегии хранения. |
| `code-analyzer.ts`        | Анализатор кода, извлекающий семантические особенности из исходного кода. |
| `embedding-generator.ts`  | Генератор эмбеддингов для текста, используя модели машинного обучения.     |
| `entity-expander.ts`      | Расширитель сущностей, преобразующий сокращения и имена в полные семантические представления. |
| `hybrid-search.ts`        | Гибридный поиск, сочетающий текстовый и векторный поиск для повышения точности. |
| `semantic-cache.ts`       | Кэширование семантических результатов для ускорения повторных запросов.     |
| `smart-chunker.ts`        | Умный чанкер для разбиения текста на логические части с сохранением смысла. |
| `vector-store.ts`         | Хранилище векторов для хранения и поиска семантических представлений текста. |
| `libsql-adapter.ts`       | Адаптер для работы с libSQL DiskANN векторным бэкендом.                   |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

Модуль используется внутри проекта для реализации семантических функций. Пример использования:

```typescript
import { SemanticCache } from './semantic/semantic-cache';
import { EmbeddingGenerator } from './semantic/embedding-generator';

const cache = new SemanticCache();
const generator = new EmbeddingGenerator();

// Генерация эмбеддинга
const embedding = await generator.generate('Пример текста');

// Кэширование результата
cache.set('key', embedding);
```

> Примечание: Все файлы модуля предназначены для внутреннего использования и не экспортируются за пределы модуля.
