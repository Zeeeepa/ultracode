# Автодокументация модуля `providers`

## 1. Описание модуля

Модуль `providers` реализует систему провайдеров для работы с различными API и сервисами, такими как OpenAI, Hugging Face, Ollama и другие. Он предоставляет унифицированный интерфейс для взаимодействия с внешними моделями и сервисами, а также поддерживает кэширование и управление HTTP-запросами.

## 2. Файлы модуля

| Файл | Описание |
|------|----------|
| `base.ts` | Базовый класс провайдера, определяющий общий интерфейс и методы для работы с API |
| `cloudru-provider.ts` | Провайдер для работы с сервисом Cloud.ru, реализующий интерфейс базового провайдера |
| `factory.ts` | Фабрика для создания экземпляров провайдеров на основе конфигурации |
| `http-engine.ts` | Модуль для управления HTTP-запросами, включая кэширование и обработку ошибок |
| `huggingface-provider.ts` | Провайдер для взаимодействия с Hugging Face API и моделями |
| `memory-provider.ts` | Провайдер, использующий локальное хранилище для кэширования результатов |
| `ollama-provider.ts` | Провайдер для работы с локальной моделью Ollama |
| `openai-provider.ts` | Провайдер для взаимодействия с OpenAI API |
| `tei-provider.ts` | Провайдер для работы с TEI (Text Embedding Inference) сервисом |
| `transformers-provider.ts` | Провайдер для работы с библиотекой Hugging Face Transformers |

## 3. Экспорты

Внутренний модуль без публичных экспортов.

## 4. Пример использования

```typescript
import { createProvider } from './providers/factory';

const provider = createProvider('openai', { apiKey: 'your-api-key' });
const result = await provider.generate('Привет, как дела?');
```
