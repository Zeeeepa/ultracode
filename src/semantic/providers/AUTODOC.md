# Провайдеры (providers)

## Описание модуля

Модуль `providers` реализует систему провайдеров для работы с различными LLM (языковыми моделями) и сервисами. Он предоставляет абстрактные классы и конкретные реализации для подключения к облачным сервисам, локальным моделям и другим источникам. Модуль использует фабричный паттерн для создания экземпляров провайдеров в зависимости от конфигурации.

## Файлы

| Файл | Описание |
|------|----------|
| `base.ts` | Базовый абстрактный класс для всех провайдеров, определяющий общий интерфейс и методы для работы с моделями |
| `cloudru-provider.ts` | Провайдер для работы с облачными моделями через API Cloud.ru |
| `factory.ts` | Фабричный класс для создания экземпляров провайдеров на основе конфигурации |
| `http-engine.ts` | Вспомогательный модуль для выполнения HTTP-запросов к API провайдеров |
| `huggingface-provider.ts` | Провайдер для работы с моделями Hugging Face через их API |
| `memory-provider.ts` | Провайдер для работы с локальным кэшированием результатов запросов |
| `ollama-provider.ts` | Провайдер для работы с локальными моделями через Ollama API |
| `openai-provider.ts` | Провайдер для работы с моделями OpenAI через их API |
| `openvino-provider.ts` | Провайдер для работы с моделями через Intel OpenVINO |
| `tei-provider.ts` | Провайдер для работы с моделями через TEI (Text Embedding Inference) |
| `transformers-provider.ts` | Провайдер для работы с моделями через библиотеку Hugging Face Transformers |

## Экспорты

Модуль не имеет публичных экспортов. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

```typescript
import { ProviderFactory } from './providers/factory';

const factory = new ProviderFactory();
const provider = factory.createProvider('openai', {
  apiKey: 'your-api-key',
  model: 'gpt-4'
});
```
