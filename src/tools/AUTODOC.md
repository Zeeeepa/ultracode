# AUTODOC.md

## 1. Название и Обзор

Модуль **tools** предоставляет вспомогательные инструменты и утилиты для работы с графами проектов, метриками агентов, обработкой данных и управлением инструментами в TypeScript-проекте. Включает компоненты для анализа кода, управления зависимостями и ограничений ответов.

## 2. Файлы

| Файл | Описание |
|------|----------|
| `agent-metrics.ts` | Сбор и обработка метрик агентов для мониторинга и анализа производительности |
| `base-tool-handler.ts` | Базовый класс для обработки инструментов, определяющий общий интерфейс и логику обработки |
| `branch-schemas.ts` | Определение схем и типов данных для работы с ветками проекта и их структурой |
| `branch-tools.ts` | Инструменты для работы с ветками, включая создание, обновление и манипуляции с ветками проекта |
| `graph-query.ts` | Утилиты для выполнения запросов к графу проекта и извлечения информации |
| `jscpd.ts` | Инструменты для поиска дублирующегося кода (Copy-Paste Detection) |
| `lerna-graph-ingest.ts` | Обработка и импорт данных графа проекта из Lerna-организаций |
| `lerna-project-graph.ts` | Работа с графом проекта, построение и управление структурой Lerna-проектов |
| `response-limits.ts` | Управление ограничениями ответов и ограничениями на объем данных |
| `tool-registry.ts` | Реестр инструментов, хранящий и управляющий доступными инструментами для выполнения задач |

## 3. Экспорты

Внутренний модуль. Нет публичных экспортов.

## 4. Использование

Данный модуль используется внутри проекта для внутренней обработки данных графа, анализа метрик и управления инструментами. Пример использования:

```typescript
import { ToolRegistry } from './tools/tool-registry';
import { LernaProjectGraph } from './tools/lerna-project-graph';

// Использование реестра инструментов
const registry = new ToolRegistry();
const tools = registry.getTools();

// Работа с графом проекта
const graph = new LernaProjectGraph();
graph.buildGraph();
```
