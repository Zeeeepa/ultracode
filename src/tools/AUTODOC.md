# Автоматическая документация модуля `tools`

## Описание модуля

Модуль `tools` предоставляет вспомогательные инструменты и утилиты для работы с графами проектов, метриками агентов, схемами веток и другими служебными функциями в TypeScript-проекте. Включает в себя обработчики инструментов, утилиты для работы с Lerna, инструменты для анализа кода и управление лимитами ответов.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `agent-metrics.ts` | Утилита для сбора и обработки метрик агентов, включая статистику по производительности и использованию ресурсов. |
| `base-tool-handler.ts` | Базовый класс для обработчиков инструментов, определяющий общий интерфейс и логику выполнения инструментов. |
| `branch-schemas.ts` | Схемы и валидаторы для работы с данными о ветках проекта, включая структуры данных и проверку корректности. |
| `branch-tools.ts` | Инструменты для работы с ветками, включая создание, обновление и манипуляции с данными о ветках проекта. |
| `graph-query.ts` | Утилита для выполнения запросов к графу проекта, включая поиск узлов и связей между ними. |
| `jscpd.ts` | Инструмент для поиска дублирующегося кода (Copy-Paste Detection) с использованием jscpd. |
| `lerna-graph-ingest.ts` | Обработчик для импорта данных о графе проекта из Lerna, включая сбор информации о зависимостях. |
| `lerna-project-graph.ts` | Утилита для построения и управления графом проекта на основе данных Lerna. |
| `response-limits.ts` | Утилита для управления лимитами ответов API, включая ограничения по времени и объему данных. |
| `tool-registry.ts` | Реестр инструментов, который управляет регистрацией и извлечением инструментов для выполнения задач. |

## Экспорты

Внутренний модуль, не содержит публичных экспортов.

## Пример использования

```typescript
// Использование инструментов из модуля
import { ToolRegistry } from './tools/tool-registry';
import { LernaGraphIngest } from './tools/lerna-graph-ingest';

const registry = new ToolRegistry();
const ingest = new LernaGraphIngest();
```

> Примечание: модуль предназначен для внутреннего использования и не экспортирует публичные API.
