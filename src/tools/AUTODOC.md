# AUTODOC.md

## 1. Название и Обзор

Модуль `tools` предоставляет вспомогательные инструменты и утилиты для работы с графами проектов, анализом кода, метриками агентов и другими служебными функциями. Включает в себя обработчики инструментов, схемы данных, анализаторы влияния и другие компоненты, необходимые для внутренней логики системы.

## 2. Файлы

| Файл | Описание |
|------|----------|
| `agent-metrics.ts` | Содержит логику для сбора и обработки метрик агентов, используемых в системе мониторинга. |
| `base-schemas.ts` | Определяет базовые схемы данных, используемые в других частях модуля для валидации и структурирования информации. |
| `base-tool-handler.ts` | Базовый класс для обработчиков инструментов, предоставляющий общую логику и интерфейсы для конкретных обработчиков. |
| `branch-schemas.ts` | Описывает схемы данных для работы с ветками проектов, включая структуры для хранения и передачи информации о ветках. |
| `branch-tools.ts` | Содержит инструменты для работы с ветками, включая анализ и манипуляции с графом проекта по веткам. |
| `graph-query.ts` | Реализует функции для выполнения запросов к графу проекта, включая поиск и фильтрацию узлов и связей. |
| `impact-analyzer.ts` | Инструмент для анализа влияния изменений в коде, определяет какие части проекта могут быть затронуты. |
| `jscpd.ts` | Утилита для поиска дублирующегося кода (Copy-Paste Detection) в проекте с использованием JSCPD. |
| `lerna-graph-ingest.ts` | Обработчик для импорта и обработки данных графа проекта, полученных из Lerna. |
| `lerna-project-graph.ts` | Логика для построения и управления графом проекта на основе структуры Lerna. |
| `response-limits.ts` | Управление лимитами ответов от инструментов, включая ограничения по времени и объему данных. |
| `tool-registry.ts` | Реестр инструментов, который отслеживает доступные обработчики и их конфигурации. |

## 3. Экспорты

Внутренний модуль. Нет публичных экспортов.

## 4. Использование

Данный модуль используется внутри системы для внутренней обработки данных графа проекта, анализа кода и управления инструментами. Пример использования:

```ts
import { ToolRegistry } from './tools/tool-registry';
import { GraphQuery } from './tools/graph-query';

const registry = new ToolRegistry();
const query = new GraphQuery();
```

Используется в основном в рамках других модулей, таких как `project-graph`, `code-analyzer` и `metrics-collector`.
