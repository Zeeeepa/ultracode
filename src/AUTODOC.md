# AUTODOC.md

## Title and Overview

Модуль `src` предоставляет основную точку входа для работы с индексацией директорий. Содержит функционал для определения текущей директории индексации и управления ею в рамках приложения.

## Files

| File        | Description                                      |
|-------------|--------------------------------------------------|
| `index.ts`  | Основной файл модуля, экспортирующий функции для работы с индексацией директорий |

## Exports

### `getCurrentIndexingDirectory`

Функция возвращает путь к текущей директории, используемой для индексации. Используется для определения целевой директории при выполнении операций индексирования файлов.

## Usage

```typescript
import { getCurrentIndexingDirectory } from './src';

const directory = getCurrentIndexingDirectory();
console.log('Текущая директория индексации:', directory);
```
