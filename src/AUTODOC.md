# AUTODOC.md

## Заголовок и Обзор

Модуль `src` представляет собой основную точку входа проекта, обеспечивающую инициализацию и управление индексированием файлов. Он предоставляет функционал для определения текущей директории индексирования и координирует работу с файловой системой. Модуль служит центральным компонентом для управления процессами индексации данных.

## Файлы

| Файл           | Описание                                                                 |
|----------------|--------------------------------------------------------------------------|
| `index.ts`     | Основной файл модуля, экспортирующий функцию для получения текущей директории индексирования |

## Экспорты

### `getCurrentIndexingDirectory`

Функция возвращает путь к текущей директории, используемой для индексирования файлов. Используется для определения точки входа в процесс индексации данных.

## Использование

```typescript
import { getCurrentIndexingDirectory } from './src';

const directory = getCurrentIndexingDirectory();
console.log('Текущая директория индексирования:', directory);
```
