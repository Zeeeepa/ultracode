# Автоматическая документация модуля `src`

## Описание модуля

Этот модуль отвечает за управление состоянием индексации данных. Он предоставляет функции для отслеживания текущего каталога индексации, проверки состояния процесса индексации и установки нового состояния. Модуль используется для координации работы с индексацией в приложении.

## Файлы модуля

| Файл         | Описание                                       |
|--------------|------------------------------------------------|
| `index.ts`   | Основной файл модуля, экспортирующий функции управления состоянием индексации |

## Экспорты

### `getCurrentIndexingDirectory`
Возвращает текущий каталог, который используется для индексации данных.

### `isIndexing`
Проверяет, выполняется ли в данный момент процесс индексации.

### `getIndexingStatus`
Возвращает текущее состояние индексации в виде объекта со статусом и дополнительной информацией.

### `setIndexingState`
Устанавливает новое состояние индексации. Принимает параметры для обновления статуса процесса.

## Пример использования

```typescript
import { getIndexingStatus, setIndexingState } from './src';

// Получение текущего состояния индексации
const status = getIndexingStatus();
console.log(status);

// Установка нового состояния
setIndexingState({
  isIndexing: true,
  currentDirectory: '/path/to/index',
});
```
