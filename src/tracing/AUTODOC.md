# Модуль трассировки (tracing)

## Описание

Модуль трассировки предоставляет инструменты для анализа условий, отслеживания потока данных, построения путей выполнения и форматирования результатов трассировки в TypeScript-проектах. Используется для мониторинга и отладки сложных логических цепочек и данных в приложении.

## Файлы

| Файл | Описание |
|------|----------|
| `condition-analyzer.ts` | Анализирует условные выражения и логические цепочки для определения возможных путей выполнения кода |
| `data-flow-analyzer.ts` | Отслеживает и анализирует поток данных между различными частями приложения |
| `index.ts` | Экспортирует основные классы модуля для использования в других частях проекта |
| `output-formatter.ts` | Форматирует результаты трассировки в читаемый и структурированный вид |
| `path-builder.ts` | Строит и управляет путями выполнения кода для последующего анализа |
| `state-tracker.ts` | Отслеживает состояние переменных и объектов в процессе выполнения программы |
| `trace-engine.ts` | Основной движок трассировки, координирующий работу всех компонентов модуля |
| `types.ts` | Определяет типы данных и интерфейсы, используемые в модуле трассировки |

## Экспорты

- **`ConditionAnalyzer`** — класс для анализа условий и логических выражений
- **`DataFlowAnalyzer`** — класс для отслеживания потока данных между компонентами
- **`OutputFormatter`** — класс для форматирования результатов трассировки
- **`PathBuilder`** — класс для построения и управления путями выполнения
- **`StateTracker`** — класс для отслеживания состояния переменных и объектов
- **`TraceEngine`** — основной движок трассировки, управляющий всеми компонентами модуля

## Пример использования

```typescript
import { TraceEngine, OutputFormatter } from './tracing';

const traceEngine = new TraceEngine();
const formatter = new OutputFormatter();

// Запуск трассировки
traceEngine.start();
// ... выполнение кода ...
traceEngine.stop();

// Форматирование результатов
const output = formatter.format(traceEngine.getTraceData());
console.log(output);
```
