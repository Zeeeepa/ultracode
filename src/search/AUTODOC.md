# Модуль поиска

## Описание

Модуль `search` предоставляет функциональность для выполнения поисковых операций с использованием шаблонов. Включает реализацию поиска по регулярным выражениям и поддержку различных стратегий сопоставления.

## Файлы

| Файл              | Описание                                                   |
|-------------------|------------------------------------------------------------|
| `pattern-search.ts` | Реализует логику поиска по шаблонам с поддержкой регулярных выражений и различных стратегий сопоставления |

## Экспорты

Модуль не предоставляет публичных экспортов. Является внутренним модулем и используется только внутри проекта.

## Использование

Модуль используется для выполнения поисковых операций внутри приложения. Пример использования:

```typescript
// Внутреннее использование в других модулях
import { search } from './search/pattern-search';

const results = search('pattern', 'text');
```
