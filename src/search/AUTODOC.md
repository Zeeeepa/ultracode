# Модуль поиска

## Описание

Модуль `search` предоставляет функциональность для выполнения поисковых операций с использованием шаблонов. Включает реализацию алгоритмов поиска по строкам и поддержку различных стратегий сопоставления.

## Файлы

| Файл | Описание |
|------|----------|
| `pattern-search.ts` | Реализация алгоритмов поиска по шаблонам, включая поиск подстрок и сопоставление с регулярными выражениями |

## Экспорты

Модуль не предоставляет публичных экспортов. Является внутренним модулем и используется только внутри проекта.

## Использование

Модуль используется для выполнения поисковых операций внутри приложения. Пример использования:

```typescript
// Внутреннее использование в других модулях проекта
import { searchInText } from './search/pattern-search';

const results = searchInText('hello world', 'world');
// Возвращает информацию о найденных совпадениях
```
