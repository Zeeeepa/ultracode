# Модуль поиска

## Описание

Модуль `search` предоставляет функциональность для выполнения поисковых операций с использованием шаблонов. Включает реализацию алгоритмов поиска по строкам и поддержку различных стратегий сопоставления.

## Файлы

| Файл              | Описание                                               |
|-------------------|--------------------------------------------------------|
| `pattern-search.ts` | Реализация поиска по шаблону с поддержкой регулярных выражений и простых строковых совпадений |

## Экспорты

Модуль не имеет публичных экспортов. Все функции предназначены для внутреннего использования внутри модуля.

## Использование

Модуль используется внутренне для выполнения поисковых операций в рамках приложения. Пример использования:

```typescript
// Внутреннее применение в другом модуле
import { searchInText } from './search/pattern-search';

const result = searchInText('hello world', 'world');
// Возвращает информацию о найденном совпадении
```
