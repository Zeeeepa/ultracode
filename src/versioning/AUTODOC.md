# Модуль версионирования

## Описание

Модуль **versioning** отвечает за управление версиями приложения и компонентов. Он предоставляет функциональность для проверки совместимости версий, обновления и миграции данных между различными версиями системы.

## Файлы

| Файл              | Описание                                            |
|-------------------|-----------------------------------------------------|
| `version-manager.ts` | Основной класс для работы с версиями, включая сравнение, проверку совместимости и управление миграциями |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

Модуль используется внутри системы для автоматической проверки версий компонентов и обеспечения совместимости при обновлениях. Пример использования:

```typescript
import { VersionManager } from './version-manager';

const versionManager = new VersionManager();
const isCompatible = versionManager.isCompatible('1.0.0', '1.2.0');
```
