# Модуль versioning

## Описание

Модуль versioning отвечает за управление версиями приложения и компонентов. Он предоставляет функциональность для сравнения версий, определения актуальности и обработки версионных данных в системе.

## Файлы

| Файл              | Описание                                       |
|-------------------|------------------------------------------------|
| `version-manager.ts` | Основной класс для работы с версиями, включая сравнение и валидацию версий |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Модуль предназначен для внутреннего использования и предоставляет функциональность через внутренние классы и функции.

## Использование

```typescript
// Пример использования (внутреннее использование)
import { VersionManager } from './version-manager';

const versionManager = new VersionManager();
const isUpdated = versionManager.isVersionGreater('1.2.0', '1.1.0');
```
