# Модуль версионирования

## Описание

Модуль `versioning` отвечает за управление версиями приложения и компонентов. Он предоставляет функционал для сравнения версий, определения актуальности и обработки версионных данных в рамках проекта.

## Файлы

| Файл              | Описание                                       |
|-------------------|------------------------------------------------|
| `version-manager.ts` | Основной класс для работы с версиями приложения, включая сравнение и валидацию версий |

## Экспорты

Отсутствуют

## Использование

Модуль предназначен для внутреннего использования и не предоставляет публичных API для прямого импорта. Он используется для автоматического управления версиями в процессе сборки и тестирования.
