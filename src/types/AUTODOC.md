# AUTODOC.md

## 1. Название и Обзор

Модуль `types` содержит внутренние типы и интерфейсы, используемые в проекте для описания структур данных, связанных с агентами, анализом хаоса, парсингом, семантикой и хранением данных. Этот модуль не экспортирует публичные символы и предназначен исключительно для внутреннего использования.

## 2. Файлы

| Файл | Описание |
|------|----------|
| `agent.ts` | Определяет типы и интерфейсы для агентов, включая их состояние, поведение и взаимодействие с системой. |
| `chaos-analysis.ts` | Содержит типы данных, используемые для описания результатов анализа хаоса и метрик устойчивости. |
| `errors.ts` | Определяет пользовательские ошибки и типы исключений, используемые в проекте. |
| `global.d.ts` | Глобальные декларации типов, расширяющие стандартные типы и добавляющие дополнительные интерфейсы. |
| `layered.ts` | Описывает структуры данных для многослойных архитектур и взаимодействия между слоями. |
| `parser.ts` | Содержит типы для парсинга входных данных, включая синтаксические деревья и результаты разбора. |
| `query.ts` | Определяет типы запросов и результатов запросов к данным, используемые в системе. |
| `semantic.ts` | Описывает семантические структуры и типы, связанные с анализом смысла и логики данных. |
| `storage.ts` | Определяет типы данных для хранения и управления состоянием в различных хранилищах. |
| `transformers.d.ts` | Декларации типов для трансформеров данных, используемых в процессе обработки. |
| `wasm-modules.d.ts` | Описывает типы модулей WebAssembly, используемых в проекте. |

## 3. Экспорты

В данном модуле **отсутствуют публичные экспорты**. Все файлы предназначены только для внутреннего использования внутри проекта.

## 4. Использование

Данный модуль используется напрямую в других внутренних модулях проекта для обеспечения типобезопасности и согласованности данных. Пример использования:

```typescript
import type { Agent } from './types/agent';
import type { Query } from './types/query';

// Использование типов в коде
const agent: Agent = {
  id: 'agent-1',
  status: 'active',
  config: {}
};

const query: Query = {
  sql: 'SELECT * FROM table',
  params: []
};
```

> Обратите внимание, что все импорты происходят из внутренних путей модуля `types` и не предназначены для экспорта за пределы проекта.
