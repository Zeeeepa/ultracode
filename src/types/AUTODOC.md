# Модуль `types`

## Описание

Модуль `types` предоставляет набор типов и интерфейсов, используемых в проекте для обеспечения типобезопасности и структурирования данных. Он включает определения для агентов, анализов, ошибок, парсинга, запросов и других компонентов системы. Этот модуль не экспортирует публичные символы и предназначен исключительно для внутреннего использования.

## Файлы

| Файл               | Описание |
|--------------------|----------|
| `agent.ts`         | Определяет типы и интерфейсы для агентов, включая их состояние, поведение и взаимодействие с системой. |
| `chaos-analysis.ts`| Содержит типы данных для анализа хаоса, включая метрики, результаты и параметры анализа. |
| `errors.ts`        | Определяет пользовательские типы ошибок и интерфейсы для обработки исключений в проекте. |
| `global.d.ts`      | Объявления глобальных типов и переменных, доступных во всём проекте. |
| `layered.ts`       | Описывает структуры данных для многослойных архитектур и взаимодействия между слоями. |
| `parser.ts`        | Определяет типы для парсеров, включая входные данные, результаты и форматы парсинга. |
| `query.ts`         | Содержит типы запросов и ответов, используемых в системе для взаимодействия с источниками данных. |
| `semantic.ts`      | Определяет семантические типы и структуры данных, используемые для анализа и обработки контента. |
| `storage.ts`       | Описывает интерфейсы и типы для хранения данных, включая структуры и методы доступа к хранилищу. |
| `transformers.d.ts`| Объявления типов для трансформеров данных, используемых в процессе обработки и преобразования. |
| `wasm-modules.d.ts`| Определяет типы модулей WebAssembly, используемых в проекте для выполнения нативных операций. |

## Экспорты

В модуле `types` отсутствуют публичные экспорты. Все типы предназначены для внутреннего использования и импортируются напрямую в другие модули проекта.

## Использование

Для использования типов из этого модуля необходимо импортировать их напрямую:

```typescript
import type { Agent, QueryResult } from './types/agent';
import type { ParseResult } from './types/parser';
```
