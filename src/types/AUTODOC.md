# AUTODOC.md

## Title and Overview

Модуль `types` содержит внутренние типы и интерфейсы, используемые в проекте для описания структур данных, связанных с агентами, анализом хаоса, парсингом и семантической обработкой. Включает определения типов для запросов, хранилищ, трансформеров и ошибок, а также глобальные декларации и спецификации WebAssembly модулей.

## Files

| Файл | Описание |
|------|----------|
| `agent.ts` | Определяет типы и интерфейсы для агентов, включая их состояние, поведение и взаимодействие с системой |
| `chaos-analysis.ts` | Содержит типы данных для анализа хаоса, включая метрики, результаты и параметры анализа |
| `errors.ts` | Определяет пользовательские типы ошибок и интерфейсы для обработки исключительных ситуаций |
| `global.d.ts` | Глобальные декларации типов, расширяющие стандартные типы и добавляющие пользовательские типы |
| `layered.ts` | Описывает структуры данных для многослойных архитектур и взаимодействия между слоями |
| `parser.ts` | Определяет типы для парсера, включая синтаксические деревья, токены и результаты парсинга |
| `query.ts` | Содержит типы запросов и результатов запросов к базам данных или API |
| `semantic.ts` | Определяет семантические типы и интерфейсы для анализа и обработки семантики данных |
| `storage.ts` | Описывает типы хранилищ, включая структуры данных, методы доступа и интерфейсы хранения |
| `transformers.d.ts` | Декларации типов для трансформеров данных, используемых в процессе обработки |
| `wasm-modules.d.ts` | Определяет типы WebAssembly модулей и их взаимодействие с TypeScript кодом |

## Exports

Нет публичных экспортов. Модуль предназначен для внутреннего использования.

## Usage

Данный модуль используется в других частях проекта для обеспечения типобезопасности и структурирования данных. Пример использования:

```typescript
import type { Agent } from './types/agent';
import type { Query } from './types/query';
import type { Storage } from './types/storage';
```
