# Автоматизация скриптов для работы с векторной базой данных

## Описание модуля

Модуль `scripts` содержит вспомогательные скрипты для управления и миграции векторной базы данных. Включает скрипт для выполнения миграций структуры базы данных и подготовки данных к использованию.

## Файлы модуля

| Файл                     | Описание                                                   |
|--------------------------|------------------------------------------------------------|
| `migrate-vector-db.ts`   | Скрипт для выполнения миграций векторной базы данных, включая создание таблиц, индексов и обновление структуры данных |

## Экспорты

В модуле отсутствуют публичные экспорты. Все файлы предназначены для внутреннего использования и запуска через CLI.

## Использование

Скрипты модуля запускаются напрямую через командную строку:

```bash
# Запуск миграции векторной базы данных
ts-node scripts/migrate-vector-db.ts
```
