# Модуль scripts

## Описание

Модуль `scripts` содержит утилиты и скрипты для выполнения различных задач в проекте, связанных с миграцией и управлением векторной базой данных. Этот модуль предназначен для внутреннего использования и не предоставляет публичных экспортов.

## Файлы

| Файл | Описание |
|------|----------|
| `migrate-vector-db.ts` | Скрипт для выполнения миграций векторной базы данных. Используется для обновления структуры и данных векторной базы при изменении схемы или добавлении новых возможностей. |

## Экспорты

Нет публичных экспортов. Модуль предназначен для внутреннего использования.

## Использование

Скрипты из этого модуля обычно запускаются через командную строку или автоматизированные процессы:

```bash
# Пример запуска миграции векторной базы данных
node scripts/migrate-vector-db.ts
```
