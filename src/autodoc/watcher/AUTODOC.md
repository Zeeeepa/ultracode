# AUTODOC.md

## Заголовок и описание

Модуль `watcher` отвечает за автоматическое обновление документации проекта при изменении исходных файлов. Он отслеживает изменения в модулях и автоматически обновляет соответствующие части документации, обеспечивая актуальность информации. Модуль также предоставляет инструменты для извлечения и анализа экспортируемых сущностей из TypeScript-файлов.

## Файлы

| Файл | Описание |
|------|----------|
| `autodoc-updater.ts` | Отвечает за обновление содержимого автоматической документации при выявлении изменений в исходных файлах. |
| `autodoc-watcher.ts` | Основной модуль отслеживания изменений файлов и управления процессом обновления документации. |
| `index.ts` | Экспортирует основные функции и классы модуля для внешнего использования. |
| `module-resolver.ts` | Предоставляет функции для определения модулей и файлов, связанных с конкретным файлом проекта. |

## Экспорты

- `diffExports` — функция для сравнения старых и новых экспортируемых сущностей.
- `generateExportDescription` — генерирует описание для экспортируемой сущности на основе её типа и содержимого.
- `updateAutodocContent` — обновляет содержимое автоматической документации для заданного файла.
- `AutoDocWatcher` — класс, реализующий логику отслеживания изменений и обновления документации.
- `getAutoDocWatcher` — возвращает экземпляр `AutoDocWatcher`, создавая его при необходимости.
- `resetAutoDocWatcher` — сбрасывает состояние `AutoDocWatcher`, очищая внутренние данные и отменяя отслеживание.
- `extractEntitiesFromContent` — извлекает список сущностей из содержимого файла TypeScript.
- `extractExportsFromContent` — извлекает экспортируемые сущности из содержимого файла TypeScript.
- `extractExportsFromFile` — извлекает экспортируемые сущности из указанного файла.
- `findEntityLine` — находит строку в файле, в которой определена указанная сущность.
- `getModuleFiles` — возвращает список файлов, входящих в указанный модуль.
- `getModuleForFile` — определяет модуль, к которому принадлежит указанный файл.

## Использование

```typescript
import { getAutoDocWatcher, AutoDocWatcher } from './watcher';

const watcher: AutoDocWatcher = getAutoDocWatcher();
watcher.startWatching(['src/**/*.ts']);
```

Данный модуль позволяет автоматически отслеживать изменения в исходных файлах и обновлять документацию в реальном времени.
