# AUTODOC.md

## Заголовок и Обзор

Модуль `generator` отвечает за автоматическую генерацию документации проекта на основе анализа исходного кода. Он предоставляет функции для сканирования модулей, генерации README-файлов и формирования архитектурной документации. Модуль используется для автоматизации процесса документирования TypeScript/JavaScript проектов.

## Файлы

| Файл | Описание |
|------|----------|
| `doc-generator.ts` | Основной модуль генерации документации, содержит логику анализа кода и формирования отчетов |
| `index.ts` | Точка входа модуля, экспортирует все публичные функции для генерации документации |

## Экспорты

- **`scanModules`** — функция для сканирования и анализа модулей проекта, собирает информацию о структуре и зависимостях
- **`generateModuleReadme`** — генерирует README-файл для отдельного модуля на основе его содержимого и комментариев
- **`generateArchitectureDoc`** — создает архитектурную документацию проекта, включая диаграммы и описания компонентов
- **`generateDocs`** — основная функция для запуска полной генерации документации проекта

## Использование

```typescript
import { generateDocs } from './generator';

generateDocs({
  projectPath: './src',
  outputPath: './docs',
  format: 'markdown'
});
```
