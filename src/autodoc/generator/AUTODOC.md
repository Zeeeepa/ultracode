# Автогенерация документации

## Описание модуля

Модуль `generator` предназначен для автоматической генерации документации проекта на основе анализа исходного кода. Он позволяет создавать архитектурные описания, модульные README-файлы и обзоры модулей. Модуль использует сканирование исходных файлов для извлечения информации о структуре проекта и генерирует соответствующую документацию в формате Markdown.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `doc-generator.ts` | Основной генератор документации, отвечает за создание архитектурных описаний и модульных README-файлов |
| `index.ts` | Точка входа модуля, экспортирует основные функции генерации документации |

## Экспорты

- **`generateArchitectureDoc`** — генерирует архитектурное описание проекта на основе анализа структуры модулей
- **`generateDocs`** — основная функция для генерации полной документации проекта
- **`generateModuleReadme`** — создает README-файл для отдельного модуля с описанием его функциональности
- **`scanModules`** — сканирует проект и собирает информацию о модулях для последующей генерации документации

## Пример использования

```typescript
import { generateDocs, scanModules } from './generator';

// Сканируем модули проекта
const modules = scanModules('./src');

// Генерируем полную документацию
generateDocs(modules);
```
