# Автогенерация документации

## Описание модуля

Модуль `generator` отвечает за автоматическую генерацию документации проекта на основе анализа исходного кода. Он позволяет создавать архитектурные документы, README-файлы для модулей и общий обзор проекта. Модуль использует сканирование файловой структуры и анализ кода для формирования структурированной документации.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `doc-generator.ts` | Основной генератор документации, отвечает за создание архитектурных описаний и README-файлов для модулей |
| `index.ts` | Точка входа модуля, экспортирует основные функции генерации документации |

## Экспорты

- **`generateArchitectureDoc`** — генерирует архитектурный документ проекта, описывает структуру и взаимосвязи модулей
- **`generateDocs`** — основная функция для генерации всей документации проекта
- **`generateModuleReadme`** — создает README-файл для конкретного модуля с описанием его функционала
- **`scanModules`** — сканирует файловую структуру проекта и собирает информацию о модулях для последующей генерации документации

## Пример использования

```typescript
import { generateDocs, scanModules } from './generator';

// Сканируем модули проекта
const modules = scanModules('./src');

// Генерируем документацию
generateDocs(modules);
```
