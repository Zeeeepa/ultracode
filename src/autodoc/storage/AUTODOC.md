# Автоматическая документация (AutoDoc)

## Описание модуля

Модуль `storage` предоставляет инфраструктуру для автоматической генерации и управления документацией проекта на основе исходного кода. Он включает механизмы для хранения и управления документационными данными, а также инструменты для автоматического извлечения информации из кода.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `autodoc-manager.ts` | Основной класс для управления автоматической документацией, отвечающий за сбор и обработку информации из исходного кода |
| `doc-storage.ts` | Хранилище для документационных данных, обеспечивающее их хранение и извлечение |
| `index.ts` | Точка входа модуля, экспортирующая основные классы и функции |
| `ref-storage.ts` | Система хранения ссылок на документационные элементы, используемая для построения перекрестных ссылок |

## Экспорты

### Классы

- **`AutoDocManager`** — основной класс для управления автоматической документацией, отвечающий за сбор информации из исходного кода
- **`DocStorage`** — класс для хранения и управления документационными данными
- **`RefStorage`** — класс для хранения и управления перекрестными ссылками в документации

### Функции

- **`getAutoDocManager`** — возвращает экземпляр `AutoDocManager`, создавая его при необходимости
- **`resetAutoDocManager`** — сбрасывает текущий экземпляр `AutoDocManager`, очищая его состояние

## Пример использования

```typescript
import { getAutoDocManager, DocStorage } from './storage';

const autoDocManager = getAutoDocManager();
const docStorage = new DocStorage();

// Использование для сбора документации
autoDocManager.collectDocumentation();
```
