# Автоматическая документация (AutoDoc) — Пользовательская документация

## Описание модуля

Модуль `storage` предоставляет инфраструктуру для автоматической генерации и управления документацией проекта на основе TypeScript-кода. Он включает механизмы для хранения и обработки информации о типах, интерфейсах, классах и функциях, а также поддерживает кэширование и ссылки на документацию.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `autodoc-manager.ts` | Основной класс для управления автоматической документацией, включая инициализацию, обновление и сброс данных. |
| `doc-storage.ts` | Хранит и управляет документационными данными, такими как описания типов и функций. |
| `index.ts` | Экспортирует основные классы и функции модуля для внешнего использования. |
| `ref-storage.ts` | Отвечает за хранение и управление ссылками на документацию, включая внутренние и внешние ресурсы. |

## Экспорты

- **`AutoDocManager`** — основной класс для управления автоматической документацией.
- **`getAutoDocManager`** — функция для получения экземпляра `AutoDocManager`.
- **`resetAutoDocManager`** — функция для сброса состояния `AutoDocManager`.
- **`DocStorage`** — класс для хранения документационных данных.
- **`RefStorage`** — класс для управления ссылками на документацию.

## Пример использования

```typescript
import { getAutoDocManager, DocStorage } from './storage';

const manager = getAutoDocManager();
const storage = new DocStorage();

// Использование для генерации документации
manager.generateDocumentation();
```
