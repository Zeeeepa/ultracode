# AUTODOC.md

## Заголовок и Обзор

Модуль `storage` предоставляет инфраструктуру для управления документами и ссылками в автоматически генерируемой документации. Он включает механизмы хранения данных, управления кэшированием и автоматической генерации документационных структур. Модуль используется для создания и поддержки документационных данных в TypeScript-проектах.

## Файлы

| Файл | Описание |
|------|----------|
| `autodoc-manager.ts` | Основной менеджер автоматической документации, отвечающий за управление процессом генерации и обновления документационных структур |
| `doc-storage.ts` | Хранилище для документационных данных, реализующее интерфейсы для сохранения и извлечения информации о документах |
| `index.ts` | Точка входа модуля, экспортирующая основные классы и функции для использования в других частях проекта |
| `ref-storage.ts` | Хранилище для ссылок, отвечающее за управление внутренними и внешними ссылками между документами |

## Экспорты

- **`DocStorage`** — класс для хранения и управления документационными данными
- **`RefStorage`** — класс для управления ссылками между документами
- **`AutoDocManager`** — основной класс менеджера автоматической документации
- **`getAutoDocManager`** — функция для получения экземпляра менеджера документации
- **`resetAutoDocManager`** — функция для сброса и пересоздания экземпляра менеджера документации

## Использование

```typescript
import { getAutoDocManager, resetAutoDocManager } from './storage';

// Получение менеджера документации
const manager = getAutoDocManager();

// Сброс менеджера (при необходимости)
resetAutoDocManager();
```
