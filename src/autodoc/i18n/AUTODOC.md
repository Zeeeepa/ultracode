# i18n

## Title and Overview

Модуль i18n отвечает за реализацию интернационализации (i18n) в приложении. Он обеспечивает автоматическое определение языка пользователя и предоставляет механизм для работы с локализованными строками. Модуль использует детектор языка для определения предпочтительного языка пользователя и управляет секциями перевода.

## Files

| File | Description |
|------|-------------|
| `index.ts` | Основной модуль i18n, который инициализирует систему локализации и предоставляет основные функции для работы с переводами. |
| `language-detector.ts` | Реализует логику определения языка пользователя на основе заголовков запроса, cookie и других источников. |
| `section-names.ts` | Определяет имена секций для различных частей приложения, которые используются при работе с переводами. |

## Exports

Нет публичных экспортов. Модуль является внутренним и не экспортирует ничего вне себя.

## Usage

```typescript
// Использование модуля i18n
import i18n from './i18n';

// Получение перевода
const greeting = i18n.t('greeting');
```

> Примечание: Модуль автоматически определяет язык пользователя при инициализации и использует его для выбора соответствующих переводов.
