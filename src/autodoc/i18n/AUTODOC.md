# Модуль i18n

## Описание

Модуль i18n отвечает за реализацию интернационализации (i18n) в приложении. Он обеспечивает автоматическое определение языка пользователя, управление секциями перевода и поддержку многоязычного интерфейса.

## Файлы

| Файл | Описание |
|------|----------|
| `index.ts` | Основной модуль, который экспортирует функции для работы с локализацией и управляет внутренним состоянием перевода |
| `language-detector.ts` | Логика определения языка пользователя на основе заголовков запроса и cookie |
| `section-names.ts` | Константы с названиями секций перевода, используемые для структурирования локализованных строк |

## Экспорты

Модуль не имеет публичных экспортов. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

Модуль используется внутри приложения для автоматической локализации контента в зависимости от языка пользователя. Пример использования:

```typescript
import { getLocalizedText } from './i18n';

// Получение переведенного текста для текущего языка
const greeting = getLocalizedText('greeting');
```
