# AutoDoc

## Title and Overview

Модуль `autodoc` предоставляет инструменты для автоматической генерации и управления документацией на основе комментариев в коде. Он позволяет извлекать ссылки на сущности, генерировать документационные комментарии и управлять хранилищем документации. Модуль особенно полезен для проектов с активной документацией и автоматическим сопровождением кода.

## Files

| File           | Description                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `index.ts`     | Основной модуль, экспортирующий все публичные функции и классы для работы с документацией |
| `types.ts`     | Определяет типы данных, используемые в модуле, включая хранилища и структуры ссылок |

## Exports

### `AutoDocManager`
Класс для управления документацией, включая добавление, обновление и извлечение сущностей и ссылок.

### `getAutoDocManager`
Функция для получения singleton экземпляра `AutoDocManager`.

### `resetAutoDocManager`
Функция для сброса и пересоздания singleton экземпляра `AutoDocManager`.

### `DocStorage`
Хранилище для хранения документационных сущностей и их ссылок.

### `RefStorage`
Хранилище для хранения ссылок на сущности в коде.

### `extractCommentRefs`
Извлекает ссылки на сущности из комментариев в коде.

### `extractReferences`
Извлекает все ссылки из исходного кода проекта.

### `generateCodeRef`
Генерирует ссылку на код с указанием строки и позиции.

### `generateDocRef`
Генерирует ссылку на документацию с указанием сущности и пути.

### `generateEntityRef`
Генерирует универсальную ссылку на сущность (функция, класс, переменная).

### `generateFlowComment`
Генерирует комментарий с указанием потока выполнения.

### `generateSeeDocComment`
Генерирует комментарий с ссылкой на документацию.

### `generateSeeEntityComment`
Генерирует комментарий с ссылкой на сущность в коде.

### `updateLineNumbers`
Обновляет номера строк в ссылках при изменении исходного кода.

### `validateReference`
Проверяет корректность ссылки на сущность или документацию.

## Usage

```typescript
import { getAutoDocManager, generateEntityRef } from './autodoc';

const manager = getAutoDocManager();
const ref = generateEntityRef('MyClass', 'path/to/file.ts');
manager.addReference(ref);
```
