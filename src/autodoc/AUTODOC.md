# Автодокументация (autodoc)

## Описание модуля

Модуль `autodoc` предоставляет инструменты для автоматической генерации и управления документацией на основе комментариев в коде. Он позволяет извлекать ссылки на сущности, генерировать документационные комментарии и управлять хранилищем документации. Используется для создания и поддержки внутренней документации проекта на основе существующего кода.

## Файлы модуля

| Файл           | Описание |
|----------------|----------|
| `index.ts`     | Основной модуль, экспортирующий все публичные функции и классы для работы с автодокументацией |
| `types.ts`     | Определяет типы данных, используемые в модуле, включая типы хранилищ и ссылок |

## Экспорты

### Классы и менеджеры

- **`AutoDocManager`**  
  Основной класс для управления автодокументацией. Отвечает за хранение, обновление и извлечение ссылок на сущности и документацию.

- **`DocStorage`**  
  Хранилище для документационных сущностей. Используется для хранения и поиска информации о документированных элементах кода.

- **`RefStorage`**  
  Хранилище для ссылок на сущности. Позволяет хранить и извлекать информацию о ссылках между элементами кода.

### Функции

- **`getAutoDocManager`**  
  Возвращает экземпляр `AutoDocManager`, создавая его при необходимости.

- **`resetAutoDocManager`**  
  Сбрасывает состояние `AutoDocManager`, очищая все хранилища.

- **`extractCommentRefs`**  
  Извлекает ссылки на сущности из комментариев в коде.

- **`extractReferences`**  
  Извлекает все ссылки из документационных комментариев и возвращает их в структурированном виде.

- **`generateCodeRef`**  
  Генерирует ссылку на код сущности по её имени и типу.

- **`generateDocRef`**  
  Генерирует ссылку на документацию для указанной сущности.

- **`generateEntityRef`**  
  Создаёт универсальную ссылку на сущность, включая тип и имя.

- **`generateFlowComment`**  
  Генерирует комментарий для указания потока выполнения или связи между сущностями.

- **`generateSeeDocComment`**  
  Создаёт комментарий с ссылкой на документацию сущности.

- **`generateSeeEntityComment`**  
  Создаёт комментарий с ссылкой на другую сущность в коде.

- **`updateLineNumbers`**  
  Обновляет номера строк в ссылках, если код был изменён.

- **`validateReference`**  
  Проверяет корректность ссылки на сущность или документацию.

## Пример использования

```ts
import { getAutoDocManager, generateDocRef } from 'autodoc';

const manager = getAutoDocManager();
const docRef = generateDocRef('MyComponent', 'component');
manager.addReference(docRef);
```

Этот пример показывает, как получить менеджер автодокументации и добавить новую ссылку на документацию для компонента.
