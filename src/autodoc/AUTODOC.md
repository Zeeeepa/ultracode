# Автодокументация (autodoc)

## Описание модуля

Модуль `autodoc` предоставляет инструменты для автоматической генерации и управления документацией в формате Markdown. Он позволяет извлекать, обновлять и структурировать документационные секции, а также управлять ссылками и хранилищами данных.

## Файлы модуля

| Файл           | Описание |
|----------------|----------|
| `index.ts`     | Основной модуль, экспортирующий все публичные функции и классы для работы с автодокументацией |
| `types.ts`     | Определяет типы данных, используемые в модуле, включая структуры секций, ссылок и хранилищ |

## Экспорты

### Классы и хранилища

- **`DocStorage`** — Хранилище для документационных секций, поддерживающее операции поиска, вставки и обновления.
- **`RefStorage`** — Хранилище для ссылок, используемых в документации, с возможностью поиска и обновления.

### Основной менеджер

- **`AutoDocManager`** — Основной класс для управления документацией, включающий логику парсинга, генерации и обновления Markdown-документов.

### Функции управления

- **`getAutoDocManager`** — Возвращает экземпляр `AutoDocManager`, создавая его при необходимости.
- **`resetAutoDocManager`** — Сбрасывает текущий экземпляр `AutoDocManager`, очищая его состояние.

### Функции работы с Markdown

- **`parseMarkdown`** — Парсит Markdown-строку и возвращает структурированные данные секций.
- **`flattenSections`** — Преобразует вложенные секции в плоский список.
- **`findSectionById`** — Находит секцию по её идентификатору.
- **`findSectionByTitle`** — Находит секцию по заголовку.
- **`updateSectionContent`** — Обновляет содержимое секции.
- **`insertSectionAfter`** — Вставляет новую секцию после указанной.
- **`generateMarkdown`** — Генерирует Markdown-строку из структурированных данных.
- **`extractTitle`** — Извлекает заголовок из Markdown-секции.
- **`getSectionPath`** — Возвращает путь к секции в документе.
- **`extractReferences`** — Извлекает ссылки из Markdown-документа.

## Пример использования

```typescript
import { getAutoDocManager, parseMarkdown } from 'autodoc';

const manager = getAutoDocManager();
const markdown = '# Введение\n\nЭто пример документации.';
const sections = parseMarkdown(markdown);

console.log(sections);
```
