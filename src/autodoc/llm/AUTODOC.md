# Модуль LLM

## Описание

Модуль LLM предоставляет инструменты для генерации и обработки документации с использованием языковых моделей. Он включает провайдеры для различных LLM (например, OpenAI, Ollama, TGI) и функции для автоматической генерации архитектурных, модульных и экспортных документов.

## Файлы

| Файл             | Описание                                                                 |
|------------------|--------------------------------------------------------------------------|
| `doc-writer.ts`  | Управляет записью и форматированием сгенерированной документации.        |
| `index.ts`       | Экспортирует основные функции и классы модуля для внешнего использования.|
| `llm-provider.ts`| Определяет интерфейсы и реализации провайдеров LLM для различных сервисов.|

## Экспорты

- **`batchGenerateDocs`** — генерирует документацию для нескольких модулей за один вызов.
- **`generateArchitectureDoc`** — создает архитектурный документ для проекта.
- **`generateExportDoc`** — генерирует документацию для экспортируемых функций и классов.
- **`generateModuleDoc`** — создает документацию для отдельного модуля.
- **`improveDoc`** — улучшает существующую документацию с помощью языковой модели.
- **`createLLMProvider`** — фабричный метод для создания экземпляра провайдера LLM.
- **`detectLLMProviders`** — автоматически определяет доступные провайдеры LLM на основе конфигурации.
- **`OllamaProvider`** — провайдер для подключения к локальной модели через Ollama.
- **`OpenAIProvider`** — провайдер для подключения к OpenAI API.
- **`TGIProvider`** — провайдер для подключения к Hugging Face Text Generation Inference.

## Использование

```ts
import { generateModuleDoc, OpenAIProvider } from 'llm';

const provider = new OpenAIProvider('sk-...');

const doc = await generateModuleDoc('./src/module.ts', provider);
console.log(doc);
```
