# Автоматическая документация LLM-модуля

## Описание модуля

Этот модуль предоставляет инструменты для автоматической генерации и улучшения документации на основе LLM (языковых моделей). Он поддерживает различные провайдеры LLM, такие как Ollama, OpenAI и TGI, и позволяет генерировать архитектурные описания, документацию модулей, экспортов и другие типы документации.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `doc-writer.ts` | Отвечает за форматирование и запись сгенерированной документации в файлы |
| `index.ts` | Экспортирует основные функции и классы модуля для внешнего использования |
| `llm-provider.ts` | Определяет интерфейсы и реализации провайдеров LLM для взаимодействия с различными API |

## Экспорты

### Функции генерации документации
- `batchGenerateDocs` — генерирует документацию для нескольких модулей за один вызов
- `generateArchitectureDoc` — создает архитектурное описание проекта
- `generateExportDoc` — генерирует документацию для экспортируемых функций и классов
- `generateModuleDoc` — создает документацию для конкретного модуля
- `improveDoc` — улучшает существующую документацию с помощью LLM

### Функции управления провайдерами
- `createLLMProvider` — создает экземпляр провайдера LLM по указанному типу
- `detectLLMProviders` — автоматически определяет доступные провайдеры LLM в среде выполнения

### Классы провайдеров
- `OllamaProvider` — реализация провайдера для локальной модели Ollama
- `OpenAIProvider` — реализация провайдера для OpenAI API
- `TGIProvider` — реализация провайдера для Hugging Face Text Generation Inference

## Пример использования

```typescript
import { generateModuleDoc, OpenAIProvider } from './llm';

const provider = new OpenAIProvider('sk-...');

generateModuleDoc('./src/my-module.ts', provider)
  .then(doc => console.log(doc))
  .catch(err => console.error(err));
```
