# AUTODOC.md

## Заголовок и Обзор

Модуль `llm` предоставляет инструменты для работы с языковыми моделями (LLM), включая создание провайдеров, генерацию документации и управление интеграциями с различными LLM-сервисами. Он поддерживает как локальные, так и облачные провайдеры, такие как Ollama, TGI и OpenAI.

## Файлы

| Файл             | Описание                                                                 |
|------------------|--------------------------------------------------------------------------|
| `doc-writer.ts`  | Отвечает за генерацию и форматирование документации по модулям и экспортируемым функциям. |
| `index.ts`       | Основной файл модуля, экспортирующий все публичные функции и классы.     |
| `llm-provider.ts`| Определяет интерфейсы и базовые классы для работы с различными провайдерами LLM. |

## Экспорты

| Экспорт                  | Описание                                                                 |
|--------------------------|--------------------------------------------------------------------------|
| `OllamaProvider`         | Провайдер для подключения к локальной LLM-модели через Ollama.          |
| `TGIProvider`            | Провайдер для подключения к LLM через Hugging Face Text Generation Inference. |
| `OpenAIProvider`         | Провайдер для подключения к OpenAI API.                                  |
| `detectLLMProviders`     | Функция для автоматического определения доступных провайдеров LLM.      |
| `createLLMProvider`      | Фабричный метод для создания экземпляра провайдера по типу.             |
| `generateModuleDoc`      | Генерирует документацию для всего модуля.                                |
| `generateExportDoc`      | Создаёт документацию для отдельных экспортируемых функций или классов.  |
| `improveDoc`             | Улучшает существующую документацию с помощью LLM.                        |
| `generateArchitectureDoc`| Генерирует архитектурную документацию модуля.                           |
| `batchGenerateDocs`      | Позволяет генерировать документацию для нескольких модулей за раз.       |

## Использование

```ts
import { createLLMProvider, OllamaProvider } from './llm';

const provider = createLLMProvider('ollama', { baseUrl: 'http://localhost:11434' });
```
