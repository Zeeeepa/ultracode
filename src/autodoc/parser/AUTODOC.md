# Автоматическая документация модуля `parser`

## 1. Название и описание

Модуль `parser` предназначен для парсинга и обработки Markdown-документов. Он предоставляет функции для извлечения структуры документа, работы с секциями, генерации ссылок и валидации ссылок. Модуль используется для анализа и манипуляции содержимым Markdown-файлов в рамках документационного проекта.

## 2. Файлы

| Файл | Описание |
|------|----------|
| `index.ts` | Основной файл модуля, экспортирующий все публичные функции парсера |
| `link-extractor.ts` | Модуль для извлечения и валидации ссылок из Markdown-документов |
| `md-parser.ts` | Основной парсер Markdown, отвечающий за разбор и генерацию структуры документа |

## 3. Экспорты

- **`parseMarkdown`** — Парсит Markdown-строку в структурированный объект с секциями и метаданными.
- **`flattenSections`** — Преобразует вложенную структуру секций в плоский массив.
- **`findSectionById`** — Находит секцию по её уникальному идентификатору.
- **`findSectionByTitle`** — Ищет секцию по заголовку.
- **`updateSectionContent`** — Обновляет содержимое секции.
- **`insertSectionAfter`** — Вставляет новую секцию после указанной.
- **`generateMarkdown`** — Генерирует Markdown-строку из структурированного объекта.
- **`extractTitle`** — Извлекает заголовок из Markdown-документа.
- **`getSectionPath`** — Возвращает путь к секции в документе.
- **`extractReferences`** — Извлекает все ссылки из документа.
- **`generateCodeRef`** — Генерирует ссылку на код (например, функцию или класс).
- **`generateEntityRef`** — Генерирует ссылку на сущность (например, модуль или тип).
- **`generateDocRef`** — Генерирует ссылку на другой документ.
- **`validateReference`** — Проверяет корректность ссылки.
- **`updateLineNumbers`** — Обновляет номера строк в секциях после изменений.

## 4. Пример использования

```ts
import { parseMarkdown, findSectionByTitle, generateMarkdown } from './parser';

const markdown = '# Заголовок\n\nСодержимое секции.';
const parsed = parseMarkdown(markdown);
const section = findSectionByTitle(parsed, 'Заголовок');
const updatedMarkdown = generateMarkdown(parsed);
```
