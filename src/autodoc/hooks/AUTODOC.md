# hooks

## Описание модуля

Модуль `hooks` предоставляет вспомогательные инструменты для работы с хуками в проекте. Включает установку хуков, проверку состояния pre-commit хуков и управление их конфигурацией. Предназначен для автоматизации процессов работы с git-хуками и обеспечения корректной работы инструментов контроля качества кода.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `hook-installer.ts` | Устанавливает git-хуки в репозиторий проекта, обеспечивая автоматическую настройку необходимых скриптов перед коммитами. |
| `index.ts` | Основной файл модуля, отвечающий за экспорт и инициализацию всех компонентов хуков. |
| `pre-commit-check.ts` | Проверяет корректность настроенных pre-commit хуков и выводит отчет о состоянии всех установленных хуков. |

## Экспорты

В модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования.

## Использование

Модуль используется в процессе настройки и управления git-хуками проекта. Пример использования:

```bash
# Установка хуков
npm run hooks:install

# Проверка состояния хуков
npm run hooks:check
```
