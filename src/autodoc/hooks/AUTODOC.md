# hooks

## Описание модуля

Модуль `hooks` отвечает за управление хуками в проекте, включая установку и выполнение pre-commit проверок. Используется для автоматизации процессов до коммита изменений в репозиторий.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `hook-installer.ts` | Отвечает за установку git хуков в проекте, включая pre-commit и другие необходимые хуки для автоматической проверки кода. |
| `index.ts` | Основной файл модуля, который экспортирует функционал для работы с хуками. |
| `pre-commit-check.ts` | Содержит логику выполнения проверок перед коммитом, включая проверку форматирования, линтеры и тесты. |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все функции предназначены для внутреннего использования и не предназначены для импорта из других модулей.

## Использование

Для использования функционала хуков в проекте необходимо выполнить установку хуков с помощью `hook-installer.ts`. Пример установки:

```bash
npm run hooks:install
```

После установки хуки будут автоматически запускаться при попытке коммита изменений.
