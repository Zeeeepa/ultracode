# hooks

## Описание модуля

Модуль `hooks` отвечает за управление хуками в проекте, включая установку и выполнение pre-commit проверок. Используется для автоматизации процессов и обеспечения качества кода перед коммитом.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `hook-installer.ts` | Отвечает за установку Git хуков в репозиторий проекта. |
| `index.ts` | Основной файл модуля, экспортирующий функционал для работы с хуками. |
| `pre-commit-check.ts` | Реализует логику выполнения проверок перед коммитом. |

## Экспорты

Внутренний модуль. Публичных экспортов нет.

## Использование

Для использования модуля необходимо вызвать соответствующие функции из `index.ts` при настройке проекта или при запуске скриптов установки хуков.

```bash
# Пример установки хуков
npm run setup-hooks
```
