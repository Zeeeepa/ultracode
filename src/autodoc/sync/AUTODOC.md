# Синхронизация данных

## Описание модуля

Модуль `sync` отвечает за синхронизацию данных между базой данных и файловой системой. Предоставляет функции для чтения и записи документов, а также для двусторонней синхронизации между различными источниками данных.

## Файлы модуля

| Файл            | Описание |
|-----------------|----------|
| `file-sync.ts`  | Реализует функции для работы с файлами, включая чтение и запись документов на диск |
| `index.ts`      | Экспортирует основные функции модуля для синхронизации данных |

## Экспорты

### `findMarkdownFiles`
Функция для поиска всех markdown-файлов в заданной директории и её поддиректориях.

### `readDocumentFromDisk`
Читает содержимое документа из файловой системы и возвращает его в формате, пригодном для обработки.

### `syncBidirectional`
Выполняет двустороннюю синхронизацию между базой данных и файловой системой, обновляя данные в обоих источниках.

### `syncDbToDisk`
Синхронизирует данные из базы данных в файловую систему, перезаписывая соответствующие файлы.

### `syncDiskToDb`
Синхронизирует данные из файловой системы в базу данных, обновляя записи в БД.

### `writeDocumentToDisk`
Записывает документ в файловую систему по указанному пути, создавая необходимые директории при необходимости.

## Пример использования

```typescript
import { syncBidirectional } from './sync';

await syncBidirectional();
```
