# Синхронизация данных

## Описание модуля

Модуль `sync` предоставляет функционал для синхронизации данных между файловой системой и базой данных. Включает инструменты для чтения, записи и двусторонней синхронизации документов в формате Markdown.

## Файлы модуля

| Файл             | Описание                                                   |
|------------------|------------------------------------------------------------|
| `file-sync.ts`   | Реализует основные функции синхронизации файлов и базы данных |
| `index.ts`       | Экспортирует все публичные функции модуля                  |

## Экспорты

### `findMarkdownFiles`
Функция для поиска всех файлов с расширением `.md` в заданной директории и её поддиректориях.

### `syncDiskToDb`
Синхронизирует данные из файловой системы в базу данных, читая документы с диска и записывая их в БД.

### `syncDbToDisk`
Синхронизирует данные из базы данных в файловую систему, читая документы из БД и записывая их на диск.

### `syncBidirectional`
Выполняет двустороннюю синхронизацию между файловой системой и базой данных, учитывая изменения в обеих сторонах.

### `writeDocumentToDisk`
Записывает документ в файловую систему по указанному пути, создавая необходимые директории при необходимости.

### `readDocumentFromDisk`
Читает документ из файловой системы по указанному пути и возвращает его содержимое в виде строки.

## Пример использования

```typescript

// Найти все Markdown файлы
const markdownFiles = findMarkdownFiles('./documents');

// Выполнить двустороннюю синхронизацию
await syncBidirectional();
```
