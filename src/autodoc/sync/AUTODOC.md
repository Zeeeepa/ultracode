# Модуль синхронизации данных (sync)

## Описание модуля

Модуль `sync` предоставляет функционал для синхронизации данных между базой данных и файловой системой. Включает в себя инструменты для чтения и записи документов, а также двустороннюю синхронизацию между различными источниками данных.

## Файлы модуля

| Файл             | Описание                                                                 |
|------------------|--------------------------------------------------------------------------|
| `file-sync.ts`   | Реализует функции для работы с файлами, включая чтение и запись документов |
| `index.ts`       | Экспортирует основные функции модуля для внешнего использования           |

## Экспорты

### `findMarkdownFiles`
Функция для поиска всех файлов с расширением `.md` в заданной директории и её поддиректориях.

### `readDocumentFromDisk`
Читает содержимое документа из файловой системы и возвращает его в виде строки.

### `syncBidirectional`
Выполняет двустороннюю синхронизацию между базой данных и файловой системой, обновляя данные в обоих источниках.

### `syncDbToDisk`
Синхронизирует данные из базы данных в файловую систему, перезаписывая соответствующие файлы.

### `syncDiskToDb`
Синхронизирует данные из файловой системы в базу данных, обновляя записи в БД.

### `writeDocumentToDisk`
Записывает содержимое документа в файл на диске, создавая необходимые директории при необходимости.

## Пример использования

```typescript
import { syncBidirectional } from './sync';

// Выполнить двустороннюю синхронизацию
await syncBidirectional();
```
