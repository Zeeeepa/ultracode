# Chaos Module

## Title and Overview

Модуль **chaos** предоставляет инструменты для анализа и обнаружения нестабильного поведения в приложении. Он включает анализ состояний и детектор хаотичного поведения, что полезно для мониторинга и отладки сложных систем.

## Files

| File | Description |
|------|-------------|
| `angular-patterns.ts` | Содержит шаблоны и паттерны для работы с Angular, используемые в анализе поведения приложения |
| `chaos-analyzer.ts` | Основной модуль для анализа хаотичного поведения системы, включая метрики и алгоритмы обнаружения |
| `index.ts` | Точка входа модуля, экспортирующая основные классы для использования в других частях приложения |
| `state-detector.ts` | Модуль для обнаружения и классификации состояний системы, используемый в анализе хаоса |

## Exports

- **`ChaosAnalyzer`** — основной класс для анализа хаотичного поведения системы, предоставляет методы для сбора метрик и обнаружения аномалий
- **`StateDetector`** — класс для определения и классификации состояний системы, используемый в процессе анализа хаоса

## Usage

```typescript
import { ChaosAnalyzer, StateDetector } from './chaos';

const analyzer = new ChaosAnalyzer();
const detector = new StateDetector();

// Использование анализатора
analyzer.analyze();

// Использование детектора состояний
detector.detect();
```
