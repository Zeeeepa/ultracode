# Chaos Module

## Title and Overview

Модуль **chaos** предоставляет инструменты для анализа состояния приложения и выявления потенциальных проблем в работе системы. Он включает анализ состояний, детекторы нестабильности и инструменты для оценки устойчивости приложения к сбоям.

## Files

| File | Description |
|------|-------------|
| `angular-patterns.ts` | Содержит определения и вспомогательные функции для работы с паттернами Angular, используемыми в анализе состояния приложения |
| `chaos-analyzer.ts` | Основной модуль анализа, отвечающий за сбор и обработку данных о состоянии системы для выявления потенциальных проблем |
| `index.ts` | Точка входа модуля, экспортирующая основные классы для использования в других частях приложения |
| `state-detector.ts` | Модуль, отвечающий за детектирование различных состояний приложения и определение нестабильности в работе |

## Exports

- **`ChaosAnalyzer`** — основной класс для анализа состояния системы и выявления потенциальных проблем
- **`StateDetector`** — класс для определения и отслеживания различных состояний приложения

## Usage

```typescript
import { ChaosAnalyzer, StateDetector } from './chaos';

const analyzer = new ChaosAnalyzer();
const detector = new StateDetector();

// Использование анализатора
analyzer.analyze();

// Использование детектора состояний
detector.detect();
```
