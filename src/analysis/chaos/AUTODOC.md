# Chaos Module

## Title and Overview

Модуль **chaos** предоставляет инструменты для анализа и обнаружения проблем в асинхронных операциях и состояниях приложений. Он включает анализатор хаоса, детектор гонок и анализатор состояний, которые помогают выявлять и устранять непредсказуемое поведение в коде.

## Files

| File | Description |
|------|-------------|
| `angular-patterns.ts` | Содержит реализацию паттернов Angular для обнаружения проблем с состоянием и асинхронностью |
| `chaos-analyzer.ts` | Основной анализатор хаоса, который отслеживает асинхронные операции и выявляет потенциальные проблемы |
| `index.ts` | Точка входа модуля, экспортирующая основные классы для использования в проекте |
| `race-detector.ts` | Компонент для обнаружения гонок данных в асинхронных операциях |
| `state-detector.ts` | Анализатор состояний, отслеживающий изменения состояний и выявляющий нестабильность |

## Exports

- **`ChaosAnalyzer`** — основной класс для анализа хаоса в асинхронных операциях
- **`RaceDetector`** — инструмент для обнаружения гонок данных между асинхронными задачами
- **`StateDetector`** — компонент для отслеживания и анализа изменений состояний
- **`StatePatternWithRaces`** — паттерн состояния с поддержкой обнаружения гонок

## Usage

```typescript
import { ChaosAnalyzer, RaceDetector, StateDetector } from './chaos';

const analyzer = new ChaosAnalyzer();
const raceDetector = new RaceDetector();
const stateDetector = new StateDetector();

// Использование компонентов для анализа
analyzer.analyze();
raceDetector.detect();
stateDetector.track();
```
