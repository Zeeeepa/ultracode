# Модуль анализа (analysis)

## Описание

Модуль **analysis** отвечает за анализ технологий и данных, используемых в проекте. Включает инструменты для определения используемых технологий и анализа их характеристик.

## Файлы

| Файл                     | Описание                                                   |
|--------------------------|------------------------------------------------------------|
| `technology-detector.ts` | Определяет используемые технологии на основе кода и метаданных |

## Экспорты

Модуль не имеет публичных экспортов. Является внутренним модулем и используется только внутри проекта.

## Использование

Модуль используется для автоматического определения технологий в проекте. Пример использования:

```typescript
// Внутреннее использование в рамках модуля
import { detectTechnology } from './technology-detector';

const tech = detectTechnology('react', '18.2.0');
console.log(tech); // Выводит информацию о технологии
```

> Примечание: Модуль предназначен для внутреннего использования и не экспортирует функции для внешнего доступа.
