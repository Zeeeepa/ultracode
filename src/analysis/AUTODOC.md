# Модуль анализа (analysis)

## Описание модуля

Модуль анализа отвечает за анализ технологий и метрик проекта. Включает инструменты для определения используемых технологий, анализа кода и формирования отчетов о состоянии проекта.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `technology-detector.ts` | Инструмент для определения используемых технологий и фреймворков в проекте на основе анализа файлов и зависимостей |

## Экспорты

Модуль не имеет публичных экспортов. Является внутренним модулем и предназначен для использования только внутри проекта.

## Использование

Модуль используется для автоматического анализа проекта и формирования отчетов о технологиях, которые используются в проекте. Пример использования:

```typescript
// Внутреннее использование в рамках проекта
import { detectTechnologies } from './analysis/technology-detector';

const technologies = detectTechnologies(projectPath);
console.log(technologies);
```
