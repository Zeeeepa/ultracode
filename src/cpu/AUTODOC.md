# Модуль CPU

## Описание

Модуль CPU отвечает за детектирование характеристик процессора и предоставляет информацию о доступных ресурсах системы. Используется для оптимизации работы приложения в зависимости от вычислительной мощности устройства.

## Файлы

| Файл             | Описание                                                   |
|------------------|------------------------------------------------------------|
| `cpu-detector.ts` | Основной файл модуля, отвечающий за определение характеристик CPU и предоставление информации о количестве ядер и частоте процессора |

## Экспорты

Модуль не имеет публичных экспортов. Все функции и классы являются внутренними и используются только внутри модуля.

## Использование

Модуль используется внутренне для настройки производительности приложения в зависимости от характеристик CPU. Пример использования:

```typescript
import { detectCpu } from './cpu/cpu-detector';

const cpuInfo = detectCpu();
console.log(`Количество ядер: ${cpuInfo.cores}`);
```
