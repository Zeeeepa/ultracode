# Модуль CPU

## Описание и Обзор

Модуль `cpu` предназначен для детектирования характеристик процессора системы. Он предоставляет информацию о количестве ядер, частоте и других параметрах CPU, что полезно для оптимизации производительности приложений и принятия решений на основе ресурсов системы.

## Файлы

| Файл              | Описание                                                   |
|-------------------|------------------------------------------------------------|
| `cpu-detector.ts` | Основной файл модуля, отвечающий за определение характеристик CPU, включая количество ядер и частоту процессора. |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все функции и классы являются внутренними и используются только внутри модуля.

## Использование

Модуль используется внутренне для получения информации о CPU. Пример использования:

```typescript
import { detectCpu } from './cpu/cpu-detector';

const cpuInfo = detectCpu();
console.log(`Количество ядер: ${cpuInfo.cores}`);
```

> **Примечание:** Внутреннее использование модуля, экспорты не предназначены для внешнего использования.
