# Shared

*Last updated: 2026-01-10*

Модуль предоставляет конфигурации и утилиты для определения и работы с языками программирования.

## Exports

| Name | Type | Description | Location |
|------|------|-------------|----------|

| `LANGUAGE_KEYWORDS` | const | Словари ключевых слов для каждого языка программирования | [→ keywords.ts:97-105] |
| `LanguageConfig` | interface | Интерфейс конфигурации языка с расширениями и правилами | [→ types.ts:13-19] |

## Files

- **index.ts** — Главный файл с переэкспортом всех публичных API модуля
- **keywords.ts** — Расширения файлов и ключевые слова языков программирования
- **types.ts** — Типовые интерфейсы для конфигураций языков и парсеров
- **utils.ts** — Вспомогательные функции для определения языка и валидации
