# Multipass

## Title and Overview

Модуль `multipass` реализует многопроходную обработку кода для TypeScript/JavaScript проектов. Он используется для анализа и трансформации исходного кода с помощью SWC парсера и обеспечивает последовательную обработку различных этапов компиляции. Модуль предназначен для внутреннего использования в системах сборки и транспиляции.

## Files

| File | Description |
|------|-------------|
| `index.ts` | Основной модуль, который экспортирует функционал оркестратора multipass. Содержит точку входа для инициализации и запуска многопроходной обработки. |
| `multipass-orchestrator.ts` | Оркестратор, который управляет последовательным выполнением нескольких проходов обработки кода. Отвечает за координацию между различными этапами трансформации. |
| `swc-fast-parser.ts` | Модуль для быстрого парсинга исходного кода с использованием SWC. Предоставляет интерфейс для анализа AST и работы с синтаксическими структурами. |
| `types.ts` | Определяет типы данных, используемые в модуле multipass. Содержит интерфейсы и типы для представления AST, проходов и результатов обработки. |

## Exports

Нет публичных экспортов. Модуль предназначен для внутреннего использования и не предоставляет публичный API.

## Usage

```typescript
import { multipassOrchestrator } from './multipass';

// Использование оркестратора для многопроходной обработки
const result = multipassOrchestrator.process(sourceCode);
```
