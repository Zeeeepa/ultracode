# Модуль parsers

## Описание

Модуль `parsers` отвечает за разбор и анализ исходного кода на различных языках программирования. Он предоставляет набор парсеров и анализаторов, которые используются для извлечения структуры, синтаксиса и семантики кода. Модуль поддерживает множество языков, включая JavaScript, TypeScript, Java, C, C++, Go, Kotlin и другие. Внутренние компоненты обеспечивают инкрементальный парсинг, анализ и интеграцию с различными парсерами и анализаторами.

| `cpp-analyzer.ts` | Анализатор C++-кода с поддержкой STL и классов. |
| `cpp-native-parser.ts` | Парсер C++-файлов с использованием нативного подхода. |
| `css-analyzer.ts` | Анализатор CSS-стилей для извлечения селекторов и правил. |
| `go-analyzer.ts` | Анализатор Go-кода для извлечения функций и структур. |

| `incremental-parser.ts` | Инкрементальный парсер для оптимизации обработки изменений. |

## Экспорты

Модуль не имеет публичных экспортов. Все файлы являются внутренними компонентами модуля.

## Использование

Данный модуль используется внутри системы для анализа и разбора исходного кода на различных языках. Пример использования:

```ts
import { parse } from './parsers/angular-parser';

const result = parse('src/app.component.ts');
```

> Примечание: Использование модуля предполагает его интеграцию с другими частями системы, например, анализаторами или линтерами.
