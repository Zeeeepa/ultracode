# AUTODOC.md

## 1. Название и описание модуля

Модуль **parsers** отвечает за анализ и разбор исходного кода различных языков программирования. Он предоставляет базовые и специализированные парсеры, анализаторы и утилиты для работы с синтаксисом, а также интеграции с внешними инструментами, такими как JavaParser и компиляторы языков. Модуль используется для построения AST (Abstract Syntax Tree), анализа структуры кода и поддержки функциональности, связанной с языковой поддержкой в проекте.

## 3. Экспорты

Внутренний модуль. Публичных экспортов нет.

## 4. Использование

Модуль используется внутри проекта для внутренней обработки и анализа исходного кода. Пример использования:

```ts
import { AngularAnalyzer } from './parsers/angular-analyzer';

const analyzer = new AngularAnalyzer();
const result = analyzer.analyze(sourceCode);
```

> **Примечание:** Все файлы модуля предназначены для внутреннего использования и не экспортируются за пределы проекта.
