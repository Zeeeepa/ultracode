# Автоматическая документация модуля `__mocks__`

## Описание модуля

Модуль `__mocks__` предназначен для хранения моков (заглушек) используемых в тестах проекта. Он содержит заглушки для сторонних зависимостей и внутренних модулей, чтобы обеспечить изолированность тестов и предсказуемое поведение при их запуске. Данный модуль не имеет публичных экспортов и используется исключительно в контексте тестирования.

## Файлы модуля

| Файл                   | Описание                                                                 |
|------------------------|--------------------------------------------------------------------------|
| `connection-pool.cjs`  | Мок для управления подключениями к базе данных. Заглушка для пула соединений. |
| `nanoid.cjs`           | Мок для генерации уникальных идентификаторов. Возвращает фиксированные значения для тестов. |
| `p-limit.cjs`          | Мок для ограничения параллельного выполнения асинхронных задач. Используется для тестирования ограниченийConcurrency. |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все файлы являются внутренними моками и используются только в тестовой среде.

## Применение

Данный модуль автоматически используется Jest при запуске тестов. Для его применения не требуется явное импортирование — Jest сам подключает моки из этого каталога при выполнении тестов.

Пример использования в тестах:
```ts
// Jest автоматически подключит моки из __mocks__
import { someFunction } from '../src/some-module';
// Здесь будут использоваться моки из __mocks__
```
