# Автоматическая документация для модуля `__mocks__`

## 1. Описание модуля

Модуль `__mocks__` предназначен для хранения заглушек (mocks) и имитаторов (spies) используемых в тестах. Он содержит заглушки для сторонних библиотек и модулей, чтобы упростить unit-тестирование и избежать реальных вызовов в тестовой среде. Данный модуль не имеет публичных экспортов и используется исключительно внутри тестовой среды.

## 2. Файлы модуля

| Файл                     | Описание                                                                 |
|--------------------------|--------------------------------------------------------------------------|
| `connection-pool.cjs`    | Заглушка для модуля управления подключениями к базе данных. Используется для имитации работы с пулом соединений. |
| `nanoid.cjs`             | Заглушка для генератора уникальных идентификаторов nanoid. Возвращает фиктивные ID для тестов. |
| `p-limit.cjs`            | Заглушка для ограничителя параллельных выполнений p-limit. Имитирует поведение ограничителя задач. |

## 3. Экспорты

В данном модуле отсутствуют публичные экспорты. Все файлы предназначены исключительно для внутреннего использования в тестовой среде.

## 4. Пример использования

Данный модуль автоматически используется Jest при запуске тестов. Пример конфигурации jest:

```json
{
  "moduleNameMapper": {
    "connection-pool": "<rootDir>/__mocks__/connection-pool.cjs",
    "nanoid": "<rootDir>/__mocks__/nanoid.cjs",
    "p-limit": "<rootDir>/__mocks__/p-limit.cjs"
  }
}
```

При импорте соответствующих модулей в тестах, Jest будет автоматически подставлять заглушки из этого каталога.
