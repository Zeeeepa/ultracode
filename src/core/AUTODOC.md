# AUTODOC.md

## Заголовок и описание

**Модуль `core`** предоставляет ядро системы, включающее механизмы управления агентами, отслеживания изменений в репозитории, управления ресурсами и взаимодействия между компонентами. Этот модуль служит основой для координации работы всего приложения и обеспечивает инфраструктурную поддержку для других частей системы.

## Файлы

| Файл | Описание |
|------|----------|
| `agent-registry.ts` | Регистр агентов, отвечающий за регистрацию, поиск и управление экземплярами агентов в системе. |
| `branch-manager.ts` | Менеджер веток, обеспечивающий работу с ветками Git, включая создание, переключение и синхронизацию. |
| `di-container.ts` | Контейнер зависимостей, реализующий паттерн внедрения зависимостей для управления жизненным циклом объектов. |
| `git-watcher.ts` | Наблюдатель за изменениями в репозитории Git, отслеживающий события и уведомляющий о новых коммитах. |
| `knowledge-bus.ts` | Шина знаний, обеспечивающая обмен данными между компонентами системы через публикацию и подписку на события. |
| `layered-index.ts` | Модуль индексации с поддержкой слоев, позволяющий организовать данные по уровням для более эффективного поиска. |
| `pipe-transport.ts` | Транспорт для передачи данных через каналы, реализующий интерфейс для обмена сообщениями между компонентами. |
| `resource-manager.ts` | Менеджер ресурсов, отвечающий за выделение, освобождение и управление ресурсами в системе. |

## Экспорты

Нет публичных экспортов. Модуль предназначен для внутреннего использования и не предоставляет публичный API.

## Использование

Данный модуль используется внутренне системой для координации работы компонентов. Пример использования:

```typescript
import { AgentRegistry } from './core/agent-registry';
import { GitWatcher } from './core/git-watcher';

// Использование внутри системы
const registry = new AgentRegistry();
const watcher = new GitWatcher();
```

> Обратите внимание, что модуль не экспортирует публичные интерфейсы и предназначен исключительно для внутреннего использования.
