# AUTODOC.md

## Заголовок и обзор

Модуль `core` представляет собой ядро приложения, обеспечивающее основные механизмы управления агентами, ресурсами, состоянием веток и взаимодействием между компонентами. Он включает в себя систему зависимостей, менеджеры ресурсов, индексацию данных и транспортные механизмы для обмена информацией. Этот модуль служит основой для работы всего приложения и обеспечивает интеграцию ключевых компонентов.

## Файлы

| Файл | Описание |
|------|----------|
| `agent-registry.ts` | Регистр агентов, отвечающий за управление жизненным циклом и идентификацией агентов в системе |
| `branch-manager.ts` | Менеджер веток, обеспечивающий работу с различными ветками данных и их синхронизацию |
| `di-container.ts` | Контейнер зависимостей, реализующий паттерн внедрения зависимостей для управления инстансами компонентов |
| `git-watcher.ts` | Наблюдатель за изменениями в репозитории Git, отслеживающий обновления и уведомляющий о них |
| `knowledge-bus.ts` | Шина знаний, обеспечивающая обмен данными и событиями между компонентами системы |
| `layered-index.ts` | Многоуровневый индекс, реализующий сложную структуру данных для быстрого поиска и доступа |
| `pipe-transport.ts` | Транспортный слой для передачи данных через каналы, поддерживающий потоковую обработку |
| `resource-manager.ts` | Менеджер ресурсов, отвечающий за выделение, освобождение и управление ресурсами приложения |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все компоненты предназначены для внутреннего использования и интеграции в ядро приложения.

## Использование

Данный модуль используется напрямую в ядре приложения для координации работы компонентов. Пример использования:

```typescript
import { CoreModule } from './core';

// Инициализация ядра приложения
const core = new CoreModule();
```

> Примечание: модуль предназначен только для внутреннего использования и не экспортирует публичные API.
