# AUTODOC.md

## Заголовок и Обзор

Модуль `core` представляет собой ядро приложения, обеспечивающее основные механизмы управления агентами, ресурсами, версионированием и взаимодействием между компонентами. Он включает в себя системы управления зависимостями, отслеживания изменений в репозитории, кэширования и транспорта данных. Этот модуль служит основой для работы всего приложения и обеспечивает интеграцию между различными подсистемами.

## Файлы

| Файл | Описание |
|------|----------|
| `agent-registry.ts` | Регистр агентов, отвечающий за регистрацию, поиск и управление жизненным циклом агентов в системе |
| `branch-manager.ts` | Менеджер ветвлений, обеспечивающий работу с ветками Git и управление изменениями в репозитории |
| `di-container.ts` | Контейнер зависимостей, реализующий паттерн внедрения зависимостей для управления объектами и их инстансами |
| `git-watcher.ts` | Наблюдатель за Git-репозиторием, отслеживающий изменения в файлах и уведомляющий о них другие компоненты |
| `knowledge-bus.ts` | Шина знаний, обеспечивающая обмен данными между компонентами через систему событий и публикацию/подписку |
| `layered-index.ts` | Модуль индексации с поддержкой слоев, реализующий структурированное хранение и поиск данных по уровням |
| `pipe-transport.ts` | Транспорт данных через каналы, обеспечивающий передачу информации между компонентами с поддержкой потоков |
| `resource-manager.ts` | Менеджер ресурсов, отвечающий за выделение, управление и освобождение ресурсов в системе |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

Данный модуль используется внутренне системой и не предполагает прямого импорта извне. Все компоненты модуля интегрируются через DI-контейнер и взаимодействуют через шину знаний или другие механизмы взаимодействия.
