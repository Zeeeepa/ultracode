# shared

## Описание модуля

Модуль `shared` содержит общие утилиты и вспомогательные компоненты, используемые в различных частях проекта. Включает в себя инструменты для работы с индексацией, контекстами выполнения, IPC-протоколами и путями хранения данных. Модуль предназначен для внутреннего использования и не предоставляет публичных экспортов.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `adaptive-worker.ts` | Управление адаптивным выполнением задач в воркерах, оптимизируя использование ресурсов в зависимости от нагрузки |
| `indexing-context.ts` | Контекст индексации, хранящий информацию о текущем состоянии процесса индексирования и параметрах поиска |
| `ipc-protocol.ts` | Определение протокола взаимодействия между процессами (IPC), включая сообщения и структуры данных |
| `project-context.ts` | Контекст проекта, содержащий информацию о текущем проекте, его конфигурации и состоянии |
| `runtime-detect.ts` | Обнаружение среды выполнения (браузер, Node.js, Electron) и предоставление соответствующих API |
| `storage-paths.ts` | Утилиты для работы с путями хранения данных, включая формирование и валидацию путей к файлам |

## Экспорты

Модуль не предоставляет публичных экспортов. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

Данный модуль используется внутренними компонентами проекта для обеспечения совместимости и переиспользования общих функций. Пример использования:

```typescript
// Внутреннее использование в других модулях
import { IndexingContext } from './shared/indexing-context';
import { RuntimeDetect } from './shared/runtime-detect';
```

Модуль не предназначен для прямого импорта извне и используется исключительно как вспомогательный компонент.
