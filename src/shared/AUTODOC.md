# Автоматическая документация модуля `shared`

## Описание модуля

Модуль `shared` содержит общие утилиты и вспомогательные компоненты, используемые в различных частях проекта. Он предоставляет функциональность для работы с адаптивными воркерами, контекстом индексации, межпроцессным взаимодействием, определениями среды выполнения и путями хранения данных. Все файлы в этом модуле являются внутренними и не экспортируют публичные интерфейсы.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `adaptive-worker.ts` | Реализует логику адаптивного воркера для параллельной обработки задач в браузере или Node.js |
| `indexing-context.ts` | Определяет контекст индексации данных, включая метаданные и параметры обработки |
| `ipc-protocol.ts` | Определяет протокол межпроцессного взаимодействия для обмена сообщениями между основным и вспомогательными процессами |
| `runtime-detect.ts` | Предоставляет функции для определения среды выполнения (браузер, Node.js, Web Worker) |
| `storage-paths.ts` | Определяет и управляет путями хранения данных в различных средах выполнения |

## Экспорты

Модуль не содержит публичных экспортов. Все функции и классы предназначены только для внутреннего использования внутри модуля.

## Пример использования

Данный модуль используется напрямую в других частях проекта и не требует прямого импорта в пользовательском коде:

```typescript
// Пример импорта внутри проекта
import { AdaptiveWorker } from './shared/adaptive-worker';
import { IndexingContext } from './shared/indexing-context';
```

> Обратите внимание, что все файлы модуля предназначены только для внутреннего использования и не должны экспортироваться за пределы проекта.
