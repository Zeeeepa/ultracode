# Модуль `modification`

## Описание

Модуль `modification` отвечает за выполнение операций по изменению кода и файлов в проекте. Включает функционал для модификации исходного кода, работы с файлами и предпросмотра изменений перед применением.

## Файлы

| Файл             | Описание |
|------------------|----------|
| `code-modifier.ts` | Реализует логику модификации исходного кода, включая замену, вставку и удаление участков кода. |
| `file-operations.ts` | Обеспечивает работу с файлами: чтение, запись, копирование и удаление файлов в рамках модификаций. |
| `preview-manager.ts` | Управляет предпросмотром изменений перед их применением, позволяет пользователю увидеть результат до сохранения. |

## Экспорты

В модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования внутри модуля.

## Использование

Модуль используется внутренне системой для выполнения операций модификации кода и файлов. Пример использования:

```typescript
// Внутреннее применение в системе
import { modifyCode } from './code-modifier';
import { performFileOperation } from './file-operations';
import { showPreview } from './preview-manager';

// Пример вызова
const result = modifyCode('src/app.ts', 'console.log("Hello")');
performFileOperation('src/app.ts', 'write', result);
showPreview(result);
```
