# Хранилище данных (storage)

## Описание модуля

Модуль `storage` предоставляет инфраструктуру для работы с графовыми данными, включая управление подключениями, кэширование, миграции схем и адаптеры для SQLite. Предназначен для внутреннего использования в системе хранения и обработки графовых структур данных.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `batch-operations.ts` | Реализует механизмы пакетных операций для эффективной обработки множественных запросов к хранилищу. |
| `cache-manager.ts` | Управляет кэшированием данных и предоставляет интерфейс для работы с кэшем в графовом хранилище. |
| `connection-pool.ts` | Обеспечивает управление пулом подключений к базе данных для оптимизации ресурсов. |
| `graph-storage-factory.ts` | Фабрика для создания экземпляров графового хранилища с различными конфигурациями. |
| `graph-storage.ts` | Основной класс для работы с графовыми данными, включая операции создания, чтения и обновления. |
| `schema-migrations.ts` | Обрабатывает миграции схемы базы данных при изменении структуры графовых данных. |
| `sqlite-adapter.ts` | Адаптер для работы с SQLite, реализующий интерфейс для выполнения SQL-запросов. |
| `sqlite-manager.ts` | Управляет инициализацией и конфигурацией SQLite-базы данных для графового хранилища. |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Пример использования

```typescript
// Использование внутри модуля
import { GraphStorage } from './graph-storage';
import { SqliteManager } from './sqlite-manager';

const storage = new GraphStorage();
const sqliteManager = new SqliteManager();
```

> Пример использования показывает инициализацию основных компонентов модуля. Внутреннее использование в рамках проекта.
