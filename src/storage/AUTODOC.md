# Модуль storage

## Описание

Модуль `storage` предоставляет инфраструктурные компоненты для работы с данными в графовой базе данных. Включает в себя управление подключениями, кэширование, миграции схем и адаптеры для работы с SQLite. Все компоненты предназначены для внутреннего использования и обеспечивают надежное и эффективное хранение графовых данных.

## Файлы

| Файл | Описание |
|------|----------|
| `batch-operations.ts` | Реализует механизмы пакетных операций для массовой вставки и обновления данных в хранилище |
| `cache-manager.ts` | Управляет кэшированием данных и метаданных для повышения производительности запросов |
| `connection-pool.ts` | Обеспечивает управление пулом подключений к базе данных с поддержкой пулинга и повторного использования соединений |
| `graph-storage-factory.ts` | Фабричный класс для создания экземпляров графового хранилища с различными конфигурациями |
| `graph-storage.ts` | Основной класс для работы с графовой структурой данных, реализует CRUD операции и навигацию по графу |
| `schema-migrations.ts` | Обеспечивает механизм миграции схемы базы данных для поддержки изменений структуры данных |
| `sqlite-adapter.ts` | Адаптер для работы с SQLite базой данных, реализует интерфейс для выполнения SQL-запросов |
| `sqlite-manager.ts` | Управляет созданием, инициализацией и конфигурацией SQLite базы данных |

## Экспорты

Внутренний модуль без публичных экспортов.

## Использование

Модуль используется внутренне системой для работы с графовыми данными. Пример использования:

```typescript
import { GraphStorageFactory } from './graph-storage-factory';

const storage = GraphStorageFactory.create();
// Используется для работы с графовой структурой данных
```
