# Стратегии (strategies)

## Описание модуля

Модуль стратегий предоставляет реализации различных стратегий делегирования и управления выполнением операций. Содержит внутренние стратегии для определения порядка выполнения и обработки результатов, используемые в системе делегирования.

## Файлы модуля

| Файл                     | Описание                                                   |
|--------------------------|------------------------------------------------------------|
| `delegation-strategy.ts` | Реализация стратегии делегирования, определяющей порядок выполнения операций и обработку результатов |

## Экспорты

В данном модуле отсутствуют публичные экспорты. Все функции и классы предназначены для внутреннего использования внутри модуля стратегий.

## Использование

Модуль используется внутренне системой делегирования и не требует прямого импорта извне. Пример использования:

```typescript
// Внутреннее применение в системе делегирования
import { DelegationStrategy } from './strategies/delegation-strategy';
```
