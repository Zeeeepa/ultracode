# Автоматизированные агенты (agents)

## Описание модуля

Модуль `agents` реализует систему автоматизированных агентов для выполнения различных задач в рамках проекта. Агенты взаимодействуют между собой для обработки данных, выполнения запросов и управления ресурсами. Модуль включает базовые классы, специализированные агенты и миксины для расширения функциональности.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `base.ts` | Базовый класс для всех агентов, определяющий общие свойства и методы |
| `conductor-orchestrator.ts` | Оркестратор, управляющий взаимодействием между агентами |
| `coordinator.ts` | Координатор, отвечающий за распределение задач между агентами |
| `dev-agent.ts` | Агент для разработки и тестирования, реализующий базовые функции |
| `dora-agent.ts` | Специализированный агент для работы с DORA метриками |
| `indexer-agent.ts` | Агент индексации данных для последующего поиска и анализа |
| `merge-agent.ts` | Агент объединения данных из различных источников |
| `parser-agent.ts` | Агент парсинга и обработки структурированных данных |
| `query-agent.ts` | Агент выполнения запросов к данным и системам |
| `resource-adjustment-mixin.ts` | Миксин для динамического управления ресурсами агентов |
| `semantic-agent.ts` | Агент семантической обработки данных и анализа контекста |

## Экспорты

Модуль не предоставляет публичных экспортов. Все компоненты предназначены для внутреннего использования и интеграции в систему агентов.

## Использование

Агенты используются внутри системы для автоматизации процессов обработки данных. Пример использования:

```typescript
import { ConductorOrchestrator } from './agents/conductor-orchestrator';

const orchestrator = new ConductorOrchestrator();
// Настройка и запуск агентов
```

> Примечание: Все агенты создаются и управляются через оркестратор, который обеспечивает их взаимодействие и координацию.
