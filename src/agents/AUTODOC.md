# Модуль agents

## Описание модуля

Модуль `agents` реализует систему агентов для выполнения различных задач в рамках проекта. Он предоставляет базовые классы и специализированные агенты для обработки данных, координации процессов и выполнения запросов. Модуль использует паттерн миксинов для расширения функциональности и поддерживает гибкую архитектуру для расширения новых типов агентов.

## Файлы модуля

| Файл | Описание |
|------|----------|
| `base.ts` | Базовый класс агента, определяющий общую структуру и методы для всех агентов |
| `conductor-orchestrator.ts` | Оркестратор, управляющий выполнением агентов в определённой последовательности |
| `coordinator.ts` | Координатор, отвечающий за распределение задач между агентами |
| `dev-agent.ts` | Агент для разработки и тестирования, реализующий базовые функции для отладки |
| `dora-agent.ts` | Специализированный агент для работы с DORA метриками |
| `indexer-agent.ts` | Агент для индексации данных и создания поисковых индексов |
| `merge-agent.ts` | Агент для объединения данных из различных источников |
| `parser-agent.ts` | Агент для парсинга и обработки структурированных данных |
| `query-agent.ts` | Агент для выполнения запросов к данным и возврата результатов |
| `resource-adjustment-mixin.ts` | Миксин для регулирования ресурсов агентов в зависимости от нагрузки |
| `semantic-agent.ts` | Агент для семантической обработки данных и извлечения смысла |

## Экспорты

Внутренний модуль без публичных экспортов.

## Использование

Пример использования агентов в системе:

```typescript
import { ConductorOrchestrator } from './agents/conductor-orchestrator';
import { IndexerAgent } from './agents/indexer-agent';
import { QueryAgent } from './agents/query-agent';

const orchestrator = new ConductorOrchestrator();
orchestrator.addAgent(new IndexerAgent());
orchestrator.addAgent(new QueryAgent());
```

> Примечание: Все агенты создаются и управляются через координатор или оркестратор, согласно архитектуре модуля.
