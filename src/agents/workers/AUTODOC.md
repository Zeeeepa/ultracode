# workers

## Описание модуля

Модуль `workers` предоставляет инфраструктуру для управления веб-воркерами и выполнения задач в изолированных потоках. Используется для параллельной обработки данных, особенно при работе с тяжелыми операциями, такими как парсинг или выполнение скриптов на Python. Модуль включает пул воркеров для различных языков и управляющий компонент для координации работы воркеров.

## Файлы

| Файл | Описание |
|------|----------|
| `generic-language-worker.ts` | Базовый класс для воркеров, поддерживающих различные языки. Определяет общий интерфейс для выполнения задач в изолированном потоке. |
| `language-worker-pool.ts` | Пул воркеров для работы с различными языками программирования. Управляет созданием и перераспределением воркеров в зависимости от типа задачи. |
| `parser-worker.ts` | Специализированный воркер для парсинга данных. Обрабатывает текстовые и структурированные данные в отдельном потоке для повышения производительности. |
| `python-worker-pool.ts` | Пул воркеров, специфичный для выполнения Python-скриптов. Управляет жизненным циклом Python-воркеров и их выполнением. |
| `python-worker.ts` | Воркер для выполнения Python-кода в изолированном потоке. Поддерживает взаимодействие с Python-скриптами и возвращает результаты в основной поток. |
| `worker-pool-manager.ts` | Управляющий компонент, отвечающий за создание, управление и освобождение ресурсов пулов воркеров. Координирует работу всех воркеров в модуле. |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

```typescript
// Использование пула воркеров для выполнения задач
import { WorkerPoolManager } from './workers/worker-pool-manager';

const manager = new WorkerPoolManager();
const pool = manager.getPool('python');
const result = await pool.execute({ script: 'print("Hello")' });
```
