# workers

## Описание модуля

Модуль `workers` предоставляет инфраструктуру для управления веб-воркерами и выполнения задач в изолированных потоках. Он включает пул воркеров для различных языков программирования, таких как TypeScript/JavaScript и Python, а также утилиты для парсинга и управления ресурсами воркеров.

## Файлы

| Файл | Описание |
|------|----------|
| `generic-language-worker.ts` | Базовый класс для создания воркеров на различных языках программирования с общей логикой обработки сообщений и управления состоянием |
| `language-worker-pool.ts` | Пул воркеров для выполнения задач на определённом языке программирования с автоматическим управлением жизненным циклом и перезапуском воркеров при необходимости |
| `parser-worker.ts` | Воркер, предназначенный для парсинга данных и обработки структурированной информации в отдельном потоке для повышения производительности |
| `python-worker-pool.ts` | Специализированный пул воркеров для выполнения задач на Python с поддержкой передачи данных и обработки результатов |
| `python-worker.ts` | Воркер для выполнения Python-скриптов в изолированном окружении с возможностью передачи параметров и получения результатов |
| `worker-pool-manager.ts` | Управляет созданием, жизненным циклом и распределением задач между различными пулами воркеров |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

```typescript
// Пример использования пула воркеров
import { WorkerPoolManager } from './workers/worker-pool-manager';

const manager = new WorkerPoolManager();
const pool = manager.getPool('python');
await pool.execute({ script: 'print("Hello")' });
```
