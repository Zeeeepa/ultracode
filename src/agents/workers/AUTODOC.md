# workers

## Описание модуля

Модуль `workers` предоставляет инфраструктуру для управления веб-воркерами и выполнения задач в изолированных потоках. Используется для параллельной обработки данных, особенно при работе с тяжелыми операциями, такими как парсинг или выполнение скриптов на Python. Включает пул воркеров для различных языков и управляющий класс для координации работы.

## Файлы

| Файл | Описание |
|------|----------|
| `generic-language-worker.ts` | Базовый класс для воркеров, поддерживающих различные языки программирования. Определяет общий интерфейс для выполнения задач. |
| `language-worker-pool.ts` | Пул воркеров для работы с разными языками программирования. Управляет созданием и перераспределением воркеров по задачам. |
| `parser-worker.ts` | Специализированный воркер для парсинга данных. Обрабатывает текстовые и структурированные данные в отдельном потоке. |
| `python-worker-pool.ts` | Пул воркеров, специфичный для выполнения Python-скриптов. Управляет жизненным циклом Python-воркеров. |
| `python-worker.ts` | Воркер для выполнения Python-кода. Поддерживает взаимодействие с Python-скриптами через посредника. |
| `worker-pool-manager.ts` | Управляющий класс, отвечающий за создание, управление и очистку пулов воркеров. Координирует работу всех воркеров в модуле. |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

```typescript
// Пример использования пула воркеров
import { WorkerPoolManager } from './workers/worker-pool-manager';

const poolManager = new WorkerPoolManager();
const parserPool = poolManager.getPool('parser');
const result = await parserPool.execute({ data: 'some data' });
```

> Примечание: Внутренний модуль, предназначенный для использования только внутри проекта.
