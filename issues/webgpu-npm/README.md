# Bun Native Addon Crash: WebGPU (dawn.node) from NPM

## Summary

Bun crashes with **Segmentation fault** when loading `webgpu` npm package (dawn.node native addon).

## Environment

- **OS**: Windows 11 (win11_dt)
- **Bun**: 1.3.4
- **Node.js**: 24.11.1 (works correctly)
- **webgpu**: 0.3.8 (from npm)
- **CPU**: Intel/AMD with SSE4.2, AVX, AVX2

## Reproduction

```bash
# Install
npm install

# Test with Node.js (works)
node test.js

# Test with Bun (crashes)
bun test.js
```

## Analysis

The crash occurs immediately after `require('webgpu')` when Bun tries to load the native addon `win32-x64.dawn.node`. The segmentation fault suggests memory access violation during N-API module initialization.

The `process_dlopen` feature is listed, confirming Bun is using its native addon loading mechanism.
