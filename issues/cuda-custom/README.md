# Bun Native Addon Crash: CUDA 13.1 (N-API)

## Summary

Bun crashes with **Segmentation fault** when loading custom CUDA native addon built with N-API and CUDA Toolkit 13.1.

## Environment

- **OS**: Windows 11
- **Bun**: 1.3.4
- **Node.js**: 24.11.1 (works correctly)
- **CUDA Toolkit**: 13.1
- **GPU**: NVIDIA RTX 5090 (Blackwell, sm_120)
- **Visual Studio**: 2022 BuildTools

## Build Info

CUDA addon built with:
- cmake-js + CMake
- Node-API (N-API) via node-addon-api
- CUDA architectures: sm_75, sm_80, sm_86, sm_89, sm_90, sm_100, sm_120

## Reproduction

```bash
# Copy ultracode_cuda.node from external-libs
copy ..\..\external-libs\cuda-win32-x64\ultracode_cuda.node .

# Test with Node.js (works)
node test.js

# Test with Bun (crashes)
bun test.js
```

## Analysis

The crash occurs at `address 0x2` which is a very low address, suggesting a null pointer dereference during N-API module initialization.

The addon exports basic CUDA vector operations:
- `cosineSimilarity` - Compute cosine similarity between vectors
- `batchCosineSimilarity` - Batch version
- `euclideanDistance` - Compute Euclidean distance
- `normalizeVectors` - Normalize vectors
- `getDeviceInfo` - Get CUDA device information

All functions work correctly in Node.js but crash immediately in Bun before any function can be called.
