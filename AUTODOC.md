# ultrascript-tools-mcp

## Описание модуля

Модуль `ultrascript-tools-mcp` предоставляет конфигурации и настройки для тестирования и сборки TypeScript-проектов. Включает конфигурации Jest для unit-тестов и настройки сборки с использованием tsup. Является внутренним вспомогательным модулем, не имеющим публичных экспортов.

## Файлы

| Файл | Описание |
|------|----------|
| `jest.config.js` | Конфигурация Jest для настройки тестовой среды, включая пути, преобразования и покрытие кода |
| `jest.setup.js` | Настройки и инициализация для Jest-тестов, включая моки и глобальные переменные |
| `jest.setup.mjs` | Модульная настройка Jest для работы с ES-модулями и импортом |
| `tsup.config.ts` | Конфигурация сборки проекта с использованием tsup, включая целевые платформы и форматы |

## Экспорты

Нет публичных экспортов. Модуль предназначен для внутреннего использования.

## Использование

Данный модуль используется в рамках сборки и тестирования проекта. Пример использования в `package.json`:

```json
{
  "scripts": {
    "test": "jest --config ./jest.config.js",
    "build": "tsup --config tsup.config.ts"
  }
}
```
