# Модуль scripts

## Описание

Модуль `scripts` содержит вспомогательные скрипты для выполнения различных задач во время разработки и установки проекта. Включает в себя скрипты для загрузки бинарных файлов, настройки GPU, сравнения результатов бенчмарков и преобразования токенизаторов. Все скрипты предназначены для автоматизации рутинных операций и обеспечения корректной работы проекта в различных средах.

## Файлы

| Файл | Описание |
|------|----------|
| `benchmark-runtime.ts` | Скрипт для запуска и измерения производительности выполнения кода в различных условиях. |
| `compare-benchmarks.ts` | Скрипт для сравнения результатов бенчмарков между различными версиями или конфигурациями. |
| `convert-tokenizer-simple.ts` | Простой скрипт для преобразования токенизатора в другой формат или структуру данных. |
| `convert-tokenizer.ts` | Скрипт для конвертации токенизатора с поддержкой расширенных опций и форматов. |
| `download-comm-binary.js` | Скрипт для загрузки коммуникационного бинарного файла из удаленного репозитория. |
| `download-native-libs.js` | Скрипт для загрузки и установки нативных библиотек, необходимых для работы проекта. |
| `postinstall-gpu.js` | Скрипт, выполняемый после установки, для настройки GPU-зависимостей и драйверов. |
| `postinstall.js` | Основной скрипт postinstall, отвечающий за общую настройку проекта после установки зависимостей. |

## Экспорты

В модуле отсутствуют публичные экспорты. Все файлы предназначены для внутреннего использования и запуска через CLI или автоматизированные процессы.

## Использование

Скрипты модуля обычно запускаются автоматически в процессе установки или сборки проекта. Пример запуска одного из скриптов:

```bash
node scripts/download-comm-binary.js
```

Или через npm-скрипты:

```json
"scripts": {
  "postinstall": "node scripts/postinstall.js"
}
```
