# AUTODOC.md

## Title and Overview

Модуль `examples` содержит демонстрационные примеры и тестовые реализации различных функциональных компонентов проекта. Включает примеры анализа данных, работы с кодом, индексацией и семантическими операциями. Все файлы предназначены для демонстрации возможностей и служат примерами использования внутренних библиотек.

## Files

| File | Description |
|------|-------------|
| `analysis-example.ts` | Пример анализа данных с использованием различных алгоритмов и методов обработки. |
| `chaos-analysis-example.ts` | Демонстрация анализа хаотичных данных и поведения систем. |
| `code-modification-example.ts` | Примеры модификации исходного кода и работы с AST-деревьями. |
| `cuda-example.ts` | Примеры использования CUDA для параллельных вычислений. |
| `demo-merge-simple.mjs` | Простая демонстрация слияния данных или кода в модуле. |
| `demo-semantic-merge.ts` | Демонстрация семантического слияния кода с сохранением смысла. |
| `layered-indexing-example.ts` | Примеры создания и использования многоуровневых индексов. |
| `parser-agent-demo.ts` | Демонстрация работы агента парсера для анализа структуры кода. |

## Exports

Нет публичных экспортов. Модуль предназначен для внутреннего использования и не предоставляет публичный API.

## Usage

Данные примеры могут использоваться для изучения функциональности и тестирования различных компонентов проекта. Для запуска примеров необходимо выполнить соответствующие скрипты или импортировать нужные файлы в контексте проекта.
