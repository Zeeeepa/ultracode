# CUDA Module

## Title and Overview

Модуль CUDA предоставляет внутреннюю интеграцию с графическими вычислениями через CUDA API. Содержит вспомогательные функции и классы для работы с GPU-вычислениями, а также управление ресурсами CUDA-устройств. Является частью системы параллельных вычислений и оптимизации производительности приложений.

## Files

| File             | Description                                                                 |
|------------------|-----------------------------------------------------------------------------|
| `index.d.ts`     | Определения типов для модуля CUDA, включая интерфейсы и типы устройств     |

## Exports

Нет публичных экспортов. Модуль предназначен для внутреннего использования и не предоставляет публичных API для импорта.

## Usage

Модуль используется внутри проекта для выполнения GPU-вычислений и не требует прямого импорта извне. Пример использования:

```typescript
// Внутреннее использование внутри проекта
import { cuda } from './cuda';
// Использование CUDA-функций для параллельных вычислений
```
