## Logs - ВСЕГДА ПРОВЕРЯЙ ЗДЕСЬ

**Пути к логам:**
```
%LOCALAPPDATA%\UltraCode\logs\
├── ultracode-YYYYMMDD.log      # Main server log (формат даты: 20260109)
└── worker-YYYY-MM-DD.log         # Worker processes log
```

**ulog CLI** - запуск через bun из корня проекта:
```bash
bun run ulog                      # Последние записи main лога
bun run ulog -- -n 100            # Последние 100 строк
bun run ulog -- -f                # Follow mode (tail -f)
bun run ulog -- -w                # Worker лог
bun run ulog -- -a                # Оба лога (main + worker)
bun run ulog -- -l E              # Только ERROR
bun run ulog -- -m INDEXER        # Фильтр по модулю
bun run ulog -- -t 5m             # За последние 5 минут
bun run ulog -- --stats           # Статистика
bun run ulog -- --emb             # Статистика embeddings
```

**Прямой запуск** (если bun недоступен):
```bash
node dist/cli/log-query/log-query-cli.js -n 50
```

**Ключевые модули**: INDEXER, DEVAGENT, ACCUMULATOR, FAISS, PARSER, WORKER, EMBEDDING

## Embedding Pipeline Stages

```
1_FILE_READ       → Чтение файлов
2_COMMENT_EXTRACT → Извлечение комментариев
3_TEXT_BUILD      → Построение текстов
4_EMBEDDING_GEN   → Генерация эмбеддингов (TEI/OVMS)
5_DB_INSERT       → Вставка в vector store
6_INDEX_REBUILD   → Пересоздание индекса
```

Логи `[PERFORMANCE]` показывают время каждого этапа.
