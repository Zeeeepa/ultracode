## Logs (scripts/read-logs.ps1)

**ВАЖНО**: Используй скрипт вместо ручных команд!

```powershell
.\scripts\read-logs.ps1 PERFORMANCE       # PERFORMANCE логи
.\scripts\read-logs.ps1 ERROR             # ERROR и FATAL
.\scripts\read-logs.ps1 -Stats            # Статистика по категориям
.\scripts\read-logs.ps1 PERFORMANCE -Lines 100 -Date 2025-12-24
```

Путь к логам: `%LOCALAPPDATA%\UltraScriptTools\logs\mcp-server-YYYY-MM-DD.log`

## Embedding Pipeline Stages

```
1_FILE_READ       → Чтение файлов
2_COMMENT_EXTRACT → Извлечение комментариев
3_TEXT_BUILD      → Построение текстов
4_EMBEDDING_GEN   → Генерация эмбеддингов (TEI/OVMS)
5_DB_INSERT       → Вставка в vector store
6_INDEX_REBUILD   → Пересоздание индекса
```

Логи `[PERFORMANCE]` показывают время каждого этапа.
