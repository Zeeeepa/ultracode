# Integration Module

## Title and Overview

Модуль интеграции предоставляет инструменты для работы с внешними системами и сервисами. Содержит реализацию тестового инструмента для взаимодействия с MCP (Model Control Protocol) системами. Модуль предназначен для внутреннего использования и не предоставляет публичных экспортов.

## Files

| File | Description |
|------|-------------|
| `test-mcp-tool.mjs` | Реализация тестового инструмента для работы с MCP протоколом. Предоставляет функционал для отправки запросов и обработки ответов от MCP сервисов. |

## Exports

Нет публичных экспортов. Модуль является внутренним и не экспортирует никакие функции или классы за пределы модуля.

## Usage

Данный модуль используется внутренне в системе для тестирования и интеграции с MCP сервисами. Пример использования:

```javascript
// Внутреннее использование
import { TestMCPTool } from './integration/test-mcp-tool.mjs';

const tool = new TestMCPTool();
// Использование инструмента для взаимодействия с MCP
```
