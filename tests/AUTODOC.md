# Тестовый модуль

## Описание

Модуль `tests` предназначен для выполнения автоматических тестов проекта. Включает в себя скрипты для запуска тестов и проверки работы различных компонентов системы. Используется для обеспечения качества кода и предотвращения регрессий.

## Файлы

| Файл | Описание |
|------|----------|
| `run-tests.js` | Основной скрипт для запуска всех тестов проекта. Обрабатывает параметры командной строки и управляет процессом выполнения тестов. |
| `test-mcp-direct.js` | Модуль тестирования прямого взаимодействия с MCP (Model Control Protocol) без использования протокола. Проверяет корректность работы напрямую с компонентами. |
| `test-mcp-protocol.js` | Модуль тестирования работы с MCP через протокол. Проверяет корректность обмена данными по протоколу и обработку сообщений. |

## Экспорты

Внутренний модуль. Нет публичных экспортов.

## Использование

Для запуска тестов выполните:

```bash
node run-tests.js
```

или

```bash
npm test
```
